## 图像说明

- 所有素材使用低饱和烟蓝灰、旧绿与灰棕的老城区冬季材质，细节风格为精细手绘写实方向。
- **住宅木门**：原始生成图带有较大透明侧留白，已按门体区域裁切并输出 96×192，方便和住宅门洞比例匹配。
- **超市门**：最终版改为可透出底下场景的真正透明玻璃区域，不再把店内货架烘焙进门片。`source_imagegen/PROP_门_超市_192x224_v01.png` 保留原始朦胧玻璃版本，`source_imagegen/PROP_门_超市_清透玻璃修订原图.png` 是正式版使用的高清来源。
- **42×50 垃圾桶**：实际游戏尺寸极小，部分细纹会被压缩得模糊，若近景特写或像素风要求严格，建议做单独像素级修整，不应放大这一低分辨率文件代替高清源。
- 窄而高的路灯、站牌等物件在输出画布内留有透明左右边距，这是为了保留细杆的真实比例。

## Godot 接入注意

1. `assets/` 可作为初版 `Sprite2D` 纹理使用，建议按 1 像素 = 1 世界单位作为初始导入比例，并保持基准点与地面接触点一致。
2. 门、卷帘门和超市自动门只有静态关闭贴图，**没有**开门、卷起、分开等动作帧；不要将其视为已完成交互资源。
3. `CollisionShape2D`、交互区域、门的进出逻辑、灯光发光效果均需在场景中单独实现。
4. 这批贴图为美术初稿，尚未在 Godot 实景中验证和人物 160 世界单位身高、住宅门洞 96×192、前景建筑贴图的最终对齐效果。

## 目录

- `assets/`：十张实际尺寸 PNG。
- `source_imagegen/`：未压缩至游戏尺寸的原始生成图和修订稿。
- `prompts/`：完整保留十份上传的原始提示词。
- `preview/十件道具总览.png`：两行五列，从左到右为上表的十项，只作为检视预览，不能作为精灵图集直接切块使用。
