## 冻结合同与质量控制

- 角色、服装、朝向：继承 `ART_CHAR_001 r03` 许知夏扶车姿态，朝右。
- 像素绘制：128×176 RGBA、**无缩放用于游戏**、Nearest、alpha 仅 0/255。
- **四帧最上方 y=0..87 的全部 88 行，直接复用 r03 原像素**，所以脸、发型、上身、手掌、握把高度完全相同；未逐帧由 AI 重绘。
- 四帧可见 bbox 的顶边均为 `y=8`，底边均为 `y=167`，可见高度严格 **160px**，脚底基线 `y=168`。每帧绘制宽度随步态不同：**70/61/55/55 px**，这是腿部张开幅度，不是人物缩放。
- 衣摆下方 y=88..167 的动作来自新的原创姿态；只在下身做小幅竖向归一，不改变上半身与角色的定位。
- 运动目标：推车时双臂不摆动、人物迈步，不再使用“扶车静止单帧整段滑行”的过渡画面。
- 现有逻辑车长96、车相对人物 `side_offset=80`、人物碰撞盒28×160、购物车 pivot(64,104)，**全部保持原值**。
