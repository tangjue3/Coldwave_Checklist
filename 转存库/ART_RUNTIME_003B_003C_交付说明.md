# 《寒潮清单》ART-RUNTIME-003B / 003C 美术交付说明

交付主题：许知夏扶购物车的静态动作、加高车把购物车、超市空货架、饮用水、食品纸箱。

**交付性质：游戏运行尺寸的像素美术候选件，尚未通过 Godot 实机验收。** 本包包含透明 PNG、原始生成母图和比例预览，不能因本包自动将素材库的审核状态改成「运行时可用」。

## 1. 与项目现状的关系

- 游戏：Godot 4.7.2，960×540 逻辑视口，32×32 世界网格，Nearest / 整倍数显示。
- 开发 Agent 的 `CORE-001B` 可能正在编写门、货架和购物车的交互。本包与该任务**并行制作**，不要求中断或覆盖其当前代码；应在它交付并复核后再接入。
- 前版 `SHOPPING_CART r01`（96×74 可见）与 160px 主角的推车动作在水平对照时手高不匹配。本包制作了一个**独立 r02 美术候选**，将可见购物车改为 96×90，保留实际轮子形状、水平占地96与脚底锚点。**不要覆盖删除 r01。**
- `ART_CHAR_001 r03` 是向右的**静止扶车动作单帧**，不是完整步行动画，也不能直接等价于现有 `r02` 行走组。
- 文件中的编号为沿用已知美术台账；具体 ID 使用与否仍以工程 `素材库/ID登记表.csv` 为唯一依据。购物车的正式 ART ID **尚待开发 Agent 核对/分配**。

## 3. 扶车图的实测装配关系

两个 Sprite 都按各自上述脚点定位。若主角脚点世界坐标是 `P`，向右扶车静态组合参考：

```text
CharacterSprite.position = P
ShoppingCartSprite.position = P + Vector2(74, 0)
```

这样手的最前端与车把接触/接近，轮子与鞋底在同一地平线。上面的 `74` 是美术静帧对齐值，**并非车体碰撞箱、交互半径或购物车状态机的硬编码建议**。在推车步行、左右翻转、不同帧之间需要重新验收手部连接，禁止把本次静帧验收直接套成完整动画通过。

本次 `02_previews/ART_CHAR_001_push_with_CART_r02_3x.png` 用 Nearest 3× 放大查看接触关系；`02_previews/ART-RUNTIME-003_combined_mock_960x540.png` 是按项目视口比例合成的**纯图片尺寸检查**，不是 Godot 运行截图。

## 4. 透明度与渲染验收

- `01_runtime_sprites/` 七张均固定尺寸，无文字、无背景，全部 alpha 只有 **0 / 255 两档**（经工具逐张验证），无半透明边缘。
- 整张图像裁出主体后，使用 Nearest 精确缩到目标像素尺寸；单图颜色数约80–120；没有引入亚像素插值或运行时缩放。
- 货架是**空设施本体**，32×32 小包装属于单独商品图；不把三阶段囤货状态画死在背景，也不冒充库存逻辑。
- 本包原始生成母图集中在 `03_source_only/`，尺寸远大于引擎贴图；不应全部装进 PCK，也不应误认这些母图可运行。
- `02_previews/` 仅是人眼审核用的拼图，**禁止作为场景背景或运行时图**。

4. 在开发实验场景使用 `TextureFilter=Nearest`、1.0 scale 接入七张 PNG，按上表脚点落位。观察人物与推车手部重叠、货架容量、商品相对人物体积，并用 960×540 运行原图截图比对。
5. 对右向静止扶车、空车、货架、商品分别给出 Godot / Web 自检结果；若之后要正式运行，再由开发 Agent 依据项目资质检查升状态、接游戏逻辑。
6. 左向扶车、扶车循环行走、装满购物车多状态、货架塞满程度变化、音效/特效/室内TileSet **均未在本包内提供**；不可宣称完成。

## 6. 当前设计判断与待验收风险

- **解决过的视觉问题**：原方案人物双手明显高于车把。新车保持 96px 水平长度，但把总可见高度调到90px；静止组合中手把衔接自然得多。
- **仍须工程验证**：车把不是 `CollisionShape2D`；扶车时脚部仍需以单行走线为准。该美术方案不等于解决了购物车阻挡角色的问题。
- **画风风险**：素材在 1× 分辨率下会进一步简化细节；如果开发 Agent 的场景整体暗度与角色产生层级冲突，应调整色板/对比度后再正式批准。
- **尺寸风险**：货架实体画布宽128而可见宽96；如果用完整画布宽做交互判定会出现“隔空点到货架”。建议以实际可见96计算互动高亮范围。

本包只做可复用、可审查的美术资源；剧情、购物结算、库存和存档由外部开发 Agent 按既定阶段推进。
