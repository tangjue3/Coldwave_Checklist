游戏接入起测：

- 在现有 Godot 项目中新增 SpriteFrames `walk_right` 四帧，按照文件名 `00 → 01 → 02 → 03`；建议从 **6–7 FPS** 起测，再以 100px/s 平移速度实际观察脚步节奏。
- `AnimatedSprite2D` 单帧画布128×176、`centered=false`、`offset=(-64,-168)`、`scale=(1,1)`、Nearest，与 r01 完全共用脚底锚点 (64,168)。
- 左行可临时镜像测试，校正 r01 报告中的 1px 光学偏差；**不要改角色物理坐标来修画面**。最终左右一致性待审核。
- 上身不能突然变大、面部不能在四帧里明显变脸、鞋底不能交替浮空；这几项以原始960×540截图和实际循环视频验证。
- 角色 r01 静止帧已经可用；r02 只代表行走动画候选，尚不包含转身、搬箱、推车姿态。

**ID纪律：** 这里使用临时自然名 `SHOPPING_CART`，不是擅自创建新的 `ART_` 正式号。开发 Agent 必须在 `素材库/ID登记表.csv` 中检查空位与预留后登记唯一编号，再按仓库命名规范重命名；不可与 `ART_FURN_101` 货架或 `ART_FURN_102` 电暖器复用 ID。

## D. 禁止误用

- `previews/*.png`、`previews/*.gif` 是观看用，不是 `SpriteFrames` 资源；预览的灰底不是素材内容。
- `99_source_not_for_runtime/*.png` 是高分辨率母图，**不能直接打进 PCK**。
- 没有制作车轮转动、车篮满载、人物扶把推车、向左独立动作。禁止把这些项目写成“已完成”。
- 这批不是购物 UI、货架 TileSet 或地图美术，不扩展功能开发范围。
