# CORE-001A：游戏角色移动底座 + ART-RUNTIME-001 单帧接入试验

请在现有《寒潮清单》Godot 4.7.2 工程中执行；本任务来自创意与美术总监，经用户委托由开发 Agent 落地。SCALE-001 报告批准按以下一版生产尺寸实施：角色可见高 160、tile32、住宅门96×192（净宽80/净高184）、超市入口192×224、货架96×192四层、购物车长96、超市主通道宽192、小包装32×32、大包装64×48/64×64、电暖器64×96。28px 角色碰撞宽度只是实机起测值，允许报告建议微调，禁止无报告擅改已锁定视觉尺度。

## A. 本次仅授权的开发任务

1. 建一个隔离的正式角色移动组件 `CharacterBody2D`：左右水平移动、停下、朝向、碰撞、脚底接地与自然镜头跟随。游戏是购物+建造的横向叙事游戏，**当前不做跳跃、攻击或平台动作**。
2. 保留现有 `GameState` / `SaveManager` / `SceneRouter` 契约，不重写项目骨架；在 `scenes/dev/` 建可单独启动的 CORE-001A 实验场景，正常主菜单启动流程不得被破坏。
3. 把本包 `01_runtime_candidates/ART_CHAR_001_r01_idle_right_128x176.png` 接入开发实验场景：128×176 是**透明动画画布**，人物可见高 160px，脚底相对于纹理左上角锚点 (64,168)。只测一张静止帧，不要伪造或自动复制成完整行走帧。
4. 在开发场景放等比例住宅门、超市入口、货架、96px 购物车占位与主通道标尺，跑通可见宽度与碰撞尺寸的对照；这些占位属于测试，不属于正式玩法或美术资源。
5. 摄像机允许平滑与死区参数化，但参数是待调项，不硬编码到美术数据；HUD 不应强迫世界地面固定 `y=416`。

## B. 严格禁止

- 不制作、补画或用外部游戏素材代替我方人物美术；不自行生成玩家正式动画。
- 不实现商店采购、货币经济、建筑经营、物资消耗、剧情对话、自动保存、正式关卡 TileSet。
- 不把概念大图、对比图、4x 预览图或带晕影高分辨率母图塞进正式 `assets/` 当作游戏可运行贴图。
- 不更改现有 ID 规则；优先查询 `素材库/ID登记表.csv` 并遵守唯一键约定。人物资产 ID 继续使用 ART_CHAR_001，旧版 v02 保留。
