# 《寒潮清单》ART-DESIGN-002｜第一季四位核心 NPC 美术设定

本包为可供讨论和审核的角色设定稿（五视图），**不是可以直接导入 Godot 作为动画使用的 Sprite Sheet**。本轮不实现正式玩法，亦不涉及第二季。

## 风格基准

- 视觉锚点：`ART_CHAR_001_v02` 许知夏已定人物画风。普通成年人比例、横版 2D 视角、精细手工像素、灰褐低饱和。
- 共同背景：中性灰石色；近景头肩头像加全身正面、左侧、右侧、背面；同一角色服装与配饰保持一致。
- 角色设计区别：每个人应有独立颜色、职业装束、发型与可识别轮廓，而不是更换主角服装颜色。
- 输入图用途：原有四位 NPC 群像仅作为身份与服装概念参考，主角 v02 仅作为画风和比例参考。

## 审核建议

四位人物与许知夏 v02 在调色、人物比例和衣物褶皱方面基本匹配，可作为第一季核心 NPC 的**外观设定基准**。需要在真实游戏缩小至目标角色高度后验证可识别性，以及左右侧面服装细节和背包位置的连贯性。若发现不同角度有小幅结构偏差，生产精灵图时统一修正，不直接裁切静态概念图冒充动画。

## 开发 Agent 入库指令

1. 将四张 PNG 复制到现有 `素材库/美术设定集/01-角色/`（资料库已经使用 `.gdignore` 与游戏运行资源隔离）。
2. 更新 `素材台账.csv` 和 `美术总览.html`，保留分类、来源说明、关联剧情 ID。审核状态可标为「已通过设定审核」，制作状态仍为「概念绘制」；运行时资源路径留空。
3. 原始合集 `ART_CHAR_002` 继续保留，用作历史群像方案；不得覆盖、移动或删除。
4. 不要在本任务中绘制动作帧、创建 SpriteFrames 或把本图复制进 `assets/characters/`。
5. 若正在执行 PREP-003，本包可以等其完成再统一收录，不打断当前工程工作。

## 下一阶段仍需的角色资产

- 表情头像：孟雨薇普通/紧张/后悔；陈叔普通/微笑；唐宁普通/疲惫；韩启程普通/焦急。
