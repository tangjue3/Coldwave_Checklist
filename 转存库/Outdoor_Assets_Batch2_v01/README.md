## 目录

- `assets/`：按各自世界尺寸导出的精确像素尺寸 PNG，带透明通道。
- `source_imagegen/`：对应未缩放原图，方便后续美术返工。

## 质量检查与限制

- 5 张 `assets/` PNG 已逐项确认宽高尺寸、RGBA 通道与透明背景。
- K 仓库初稿错误地带有右侧物流棚；已重做为单独的连续仓库立面，保留五扇大型装卸门。
- U 护栏透明洞口已叠加灰底检查，呈现为透明空隙，无不透明红黄背景块。原图在黑底预览时可能显示透明像素中残留的彩色 RGB，这不是不透明色块。
- H/K/L 的生成原图画幅比例与目标占位比例不完全一致；导出采用非等比重采样以满足准确目标尺寸，正式精修应检查门洞、卷帘门与人物比例。
- 该批为场景集成候选 v01，还未在 Godot 中完成角色门洞 96×192、碰撞、遮挡和互动拆层验证；不能因图片像素尺寸正确就直接视为最终可交互场景资产。
