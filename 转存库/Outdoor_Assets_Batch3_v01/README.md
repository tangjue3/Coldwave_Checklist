## 文件结构

- `assets/`：已按目标尺寸导出的透明 PNG，可供 Godot 作为初版 `Sprite2D` 使用。
- `source_imagegen/`：未缩放的原始生成图，供后续修图或重导出。

## 技术与质量说明

1. 图像整体采用正立面方向，背景为透明通道；无地面铺装及天空背景。
2. 四张最终 PNG 的像素尺寸与对应世界尺寸一致，建议以 **1 像素 = 1 游戏世界单位** 作为初始导入配置，具体缩放与项目的世界单位设置保持一致。
3. 生图无法确保每根门框、栏杆及单个门洞达到严格的物理碰撞尺度，住宅门洞 `96 × 192` 等要求须在 Godot 内结合玩家碰撞体测量和调整。
4. 车棚中的自行车、电动车，以及院墙的门叶仍属于**同一平面整体贴图**；需要交互或遮挡层级时，后续应拆层并重建独立对象及碰撞体。
5. 本包为可供场景试拼的美术初稿，不等同于已通过 Godot 实机比例、碰撞或交互验收的最终可交互场景资源。
