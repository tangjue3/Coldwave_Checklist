# 本批素材生成记录

模式：内置图像生成工具（无外部 API key），以此前批准的许知夏静止母图作为人物风格与角色身份参考。

## 行走四帧提示词核心约束

- 类型：2D 横版游戏可拆分的四格人物动作条，四个等宽单元，全身、严格向右90°侧视。
- 主角身份：同一张成熟深棕马尾女生面部与头身比例、同一件补丁灰蓝色工装外套、橄榄色内衬、棕色工装裤和鞋；每格只两手两脚。
- 姿态：`contactA → passing → contactB → passingB`，步幅克制，脚底同线，头像与身高不变。
- 背景：真实 RGBA 透明，不得有黑色晕影、环境、文字、分栏线或道具。
- 输出后按原始四格分割，采用同一缩放比例与共同水平角色轴，制作四张 128×176 的透明 PNG；脚底锚点 (64,168)。

## 空购物车提示词核心约束

- 类型：横版像素生存游戏中真实可用的空超市购物推车，单一物体侧面精灵。
- 外形：向右车头、左边把手、稀疏金属网篮、梯形篮框、下方金属支撑与两组脚轮，磨损金属冷灰和少量暖锈迹，严格侧视。
- 比例：相对160px高主角，购物车目标实际宽96px、高约74–80px；头部不应比玩家高。
- 背景：透明，车篮孔洞也是透明；无产品、道具、人物、阴影、环境或文字。
- 输出后统一真实宽96px，嵌在 128×112 透明帧，脚底锚点 (64,104)。

这两份描述用于复现创作意图；具体画面仍必须按已交付源图与引擎截图人工审查，不保证相同提示词重新生成能得到像素完全相同的图片。
