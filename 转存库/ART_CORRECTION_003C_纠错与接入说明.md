# 《寒潮清单》ART-FIX-003C｜商品图对应关系修正

**此包用于修正 ART-INTEGRATE-003 发现的商品美术缺陷，不是新玩法或新物品。**

## 1. 错误范围与责任

原 ART-RUNTIME-003C 交付时，我把两份图片生成母图的来源对应关系认反了，导致 `ART_ITEM_101`（水）实际画成纸箱、`ART_ITEM_102`（食品纸箱）实际画成饮用水。错误不仅涉及 32×32 货架衍生版，**64×48 和 64×64 落地版也同时受影响**。原包对这些文件的文字描述和 PNG 内容不符。

已逐张目视复核原始 PNG 后重新从正确母图制作，不把蓝色像素直接换名来冒充物体结构。

## 3. 给 Godot Agent 的修正流程

1. 将旧商品四图保留在美术台账和历史转存中，备注 `r01 / r01-shelf：**素材内容与 ID 对应错误，不予审核通过**`。不要删除已有文件，更不能将旧版提升为运行时可用。
2. 将本包四张图收录为对应稳定 ID 的 `r02 / r02-shelf`，执行 ID 登记校验。仍只有两个物品 ID，不新增水、纸箱等 ID。
3. 先在独立开发场景接入四张图，核对截图：`101` 必须是蓝灰色六瓶水，`102` 必须是棕色红胶带纸箱；两种尺寸和两种货架版本均各检查一次。
4. 商品 UI 文案 / 图像 / 物品 ID / 商品类别的映射应一致；不要让旧错误 PNG 的占位文件名污染后续的购物系统。
5. 验证四张的画布、透明度、脚点、四层货架能否摆放，然后运行 Windows / Web 回归。只有通过后才能将 `r02` 候选升为运行时可用。
6. 将此次错误记入 `docs/` 与素材台账，更新素材库离线预览，不修改主角、车体碰撞、经济数值或购物逻辑。

## 4. 总监同步裁定

- `ART_CHAR_001 r03`：**批准阶段运行时可用**，只用于“扶车待机”；不能宣称“扶车行走完成”。
- `ART_FURN_103 r02`：**批准阶段运行时可用**，承认加高车把对齐有效。后续 `r03` 独立图层分件要另外验收。
- `ART_FURN_101 r01`：**批准阶段运行时可用**，定义为四层、内宽90、各层净空34–35像素；48px高包装必须落地。
- `ART_ITEM_101 / 102 r01` 与 `r01-shelf`：**拒绝审核通过**，错误图不许进入正式购物物品表。
- `ART_ITEM_101 / 102 r02` 与 `r02-shelf`：本次美术纠错候选，待 Godot 实机与数据映射检查通过后，再申请审批。
- 手部扶车握在端帽（间隙1–2px）：准许作为测试过渡，**不批准作为最终推车动画**；下一套推车连续帧要设计拳头握住握把中段，不能改冻结的80px物理间距。
- 推车移动时静止帧滑行：允许作为当前测试占位，不允许进入正式对外演示的画面。等新推车步行帧后切换。
