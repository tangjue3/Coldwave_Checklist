# 转存库（素材收录入口）

这里是用户 / 总策划投递新素材的**临时收件箱**，不是游戏运行时资源，也不是正式美术设定库。

流程：

1. 新素材先放这里，保留原始文件名。
2. 由开发 Agent **复制**（不移动、不删除）到 `素材库/美术设定集/` 对应分类，按 `ART_*_vNN_名称` 命名。
3. 在 `素材库/素材台账.csv` 新增一行，写明来源、状态、授权与运行时路径。
4. 运行 `python tools/build_artlib.py` 重建缩略图与离线预览页。
5. 本目录保留原始投递件，方便核对 SHA-256 与追溯来源。

本目录中的文件**不会**被 Godot 导入（根目录有空的 `.gdignore`，与 `素材库/` 同规则）；
`素材库/美术总览.html` 里的「原始来源」链接会指向这里，因此本目录随仓库保留。
