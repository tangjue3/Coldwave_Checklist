# 测试

## 启动自检

```bash
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --path .
```

由 `scenes/dev/test_scene.tscn` 触发，检查引擎版本、视口、像素渲染设置、输入映射、资源可加载性，并把截图写到 `screenshots/`，随后自动退出。

- 退出码 `0`：全部通过
- 退出码 `1`：存在失败项，终端里以 `[SMOKE][FAIL]` 标出

## screenshots/

保留每次启动的截图，用于**渲染回归对比**：改动渲染设置、缩放模式或字体后，前后两张图应当肉眼一致。
文件名带时间戳，不需要手工清理；如果积累过多，按里程碑清理旧图即可。

## 后续（不在本阶段）

无 UI 的逻辑测试要能脱离画面运行，直接用 `godot --headless --script` 执行：
购物车结算、库存增减、抗寒/供电结算、剧情 flag 分支、存档读档一致性。
这些测试等对应系统实现后再建，本阶段不预写空壳。
