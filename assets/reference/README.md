# 画风参考图（不是可用素材）

本目录两张图来自 v1.0 交接包，用于确定美术方向，**不是可以直接使用的游戏资源**。

| 文件 | 原文件名 | 内容 | 用途 |
|---|---|---|---|
| `reference_character_style.png` | 参考_用户指定角色画风.png | 女性角色侧身像，精细像素、正常比例、补丁工装 | 确定主角像素密度与配色 |
| `reference_store_and_shelter.png` | 参考_超市与安全屋概念图.png | 左：超市货架；右：两层剖面安全屋 | 确定场景构图与冷暖对比 |

## 使用边界

- 只提炼**风格特征**：像素密度、轮廓处理、低饱和配色、室内暖光与室外冷调的对比。
- **不得**抠图、描摹同一人物身份、直接缩放后当 sprite 使用。两张图均为 AI 生成的概念图，没有逐帧一致性，也没有可用的行走/待机帧。
- 正式素材必须是统一分辨率的原创 spritesheet（见 `docs/开发说明.md` 第 5 节）。

## 已下的技术结论

- 角色参考图的分辨率与细节量说明：主角目标是 80–110px 宽、160–210px 高，动画帧需要手工重绘，不能靠缩小概念图得到。
- 概念图的透视（超市是斜侧、安全屋是正剖面）不是最终游戏中应采用的统一视角，落地时以**真侧视 / 正剖面**为准。
