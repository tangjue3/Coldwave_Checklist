# 数据文件（本阶段为空）

计划存放的数据配置，v1.1 交接包到位后再创建：

| 文件 | 内容 |
|---|---|
| `items.json` | 物品：id / 名称 / 价格 / 体积 / 堆叠 / 消耗速率 / 货架类型 |
| `facilities.json` | 设施：占用格、耗电、抗寒加值、安装条件 |
| `shops.json` | 商店、货架与可售商品池 |
| `economy.json` | 价格系数、每日所需抗寒、食物/水消耗、天数节奏 |
| `story_main.json` | 主线事件（P00–P07 / D00–D07） |
| `story_optional.json` | 支线事件（S01–S06） |
| `localization_zh.json` | 文本表（若采用 key 索引方案） |

## 为什么不现在就写

v1.0 的数值已验证需要重平衡：开局 48,000 元相对总开销不到 4 成、抗寒阈值低于纯被动材料叠加值、容量与行动点都不会触顶。
先落数据等于把已知有问题的数值固化进代码，所以暂停到 v1.1。

**约束**：任何数值只能出现在这里，不许写进脚本。读取失败时应有明确报错，不要静默用默认值兜底。
