# 动画素材记录规范（ARTLIB-001 建立，本轮只立规范）

> 本文件定义「将来如何记录动画」，**不代表任何动画已经完成**。
> 当前素材库没有 sprite sheet、GIF、APNG 或视频动画；一张概念立绘永远不能被登记为可运行角色动画。

## 1. 必须支持的动画类型

| 类型 | 说明 | 建议素材 ID 前缀 |
|---|---|---|
| 角色动作设定 | 站立 idle、行走 walk、交互 shop/interact、搬运 carry | `ART_CHAR_` |
| 精灵图 Sprite Sheet | 透明背景、每帧同一画布、脚底基准线一致 | `ART_CHAR_` / `ART_FX_` |
| 动画预览 | GIF / APNG / MP4（WebM 亦可），用于审核播放效果 | `ART_FX_` |
| 环境特效 | 飘雪、结霜、暖灯、发电机运转、窗外雪层变化 | `ART_FX_` |
| UI 动效 | 购物车变满、货架填充、按钮状态（后续） | `ART_UI_` |

## 2. 角色方向设计

每个可动角色需要记录方向设计，缺一项就写「未制作」，不能留空冒充完成：

- `正面` / `背面` / `左侧面` / `右侧面`（可用镜像时注明「右侧面由左侧面水平翻转」）
- 四方向一致的：发型、服装配色、随身物件、身高与像素密度
- v1.1 `05` 的主角设定提案是**四视区概念图**，只是风格参考，不是可运行方向帧

## 3. 台账中必须填写的动画字段

`素材台账.csv` 为动画预留了以下列（非动画素材填空或 `不适用`）：

| 字段 | 格式 / 示例 | 说明 |
|---|---|---|
| `动画帧数` | `4` / `6` / `4-6` | idle 4 帧、walk 6 帧是 v1.0 GDD 的最低要求 |
| `帧率FPS` | `8` / `12` | 播放速度，必须写明，不能只说「正常速度」 |
| `尺寸` | `96x192` | 单帧像素尺寸；主角试稿约 96×192，最终以实际素材为准 |
| `方向` | `正面/背面/左侧面/右侧面` | 已绘制的方向列表 |
| `预览文件` | `美术设定集/05-特效与动画/ART_FX_001_v01.gif` | GIF / APNG / 视频的相对路径 |
| `精灵图文件` | 同上，`.png` | 仅当真正存在 spritesheet 时填写 |

审核时按「精灵图文件是否存在 + 帧数 / FPS / 尺寸是否填写 + 方向是否齐 + 预览是否可播放」逐项核对。

## 4. 文件命名

```
ART_CHAR_001_v01_idle.png              单帧 / 序列
ART_CHAR_001_v01_walk_sheet.png        精灵图
ART_CHAR_001_v01_walk_preview.gif      预览动画
ART_FX_001_v01_snow_loop.apng          循环特效预览
```

多版本并存：`v02` 另起一行台账，注明「替代 v01 的原因」；不要覆盖 `v01`。

## 5. 与运行时资源的分界

- 本库里的 spritesheet / GIF 只是**审核用设定资料**，Godot 因 `.gdignore` 不会导入。
- 进入 `assets/characters/` 的正式 sprite 必须：统一像素密度、透明背景、帧对齐、已在 Godot 中实际播放验证通过。
- 台账 `审核状态` 必须先到 `运行时可用`，并填 `对应运行时资源路径`。
- 预览页会显示「动画预览」字段；若 `精灵图文件` 为空却标了 `运行时可用`，视为台账错误，必须修正。
