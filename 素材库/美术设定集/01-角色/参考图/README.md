## 用途与限制

- **只给用户做 AI 视频参考图**，和 ChatGPT 给的提示词一起喂给视频模型。
- **不是 Godot 运行时精灵**：不进 `assets/`，不进 SpriteFrames，不参与任何游戏加载。
- **不占素材 ID**：它们是同一张 v02 的派生裁图，不是新素材、也不是 v02 的新版本，
  给它们编号会污染号段。这一点和 `03-物品与家具/验收对照/` 是同一套规则。
- 不得基于这些图重新设计人物。要改外观必须先经美术总监批准并出新的 `v03`。
