`ART_CHAR_001` 起编号。存放主角、NPC 的设定卡、四视图、表情、侧影与像素试稿。

- 概念图、参考图、废弃版本都可以并存，用 `v01` / `v02` 区分。
- 用户提供的外部角色图只能作为**风格参考**，见台账 `版权或授权备注`。
- 站立 / 行走 / 交互 / 搬运等动作设定与精灵图预览的字段约定见 `05-特效与动画/动画素材记录规范.md`。
- **当前基准**：`ART_CHAR_001_v02_许知夏_五视图设定候选.png` 为第一季主角外观基准（已通过设定审核），
  `v01` 保留为历史备选。两者都只是设定稿，**不是可运行 Sprite Sheet**。
- **第一季核心 NPC 基准**（ART-DESIGN-002，均已通过设定审核、均为五视图设定稿）：
  - `ART_CHAR_104_v01_孟雨薇_角色五视图.png`
  - `ART_CHAR_105_v01_陈叔_角色五视图.png`
  - `ART_CHAR_106_v01_唐宁_角色五视图.png`
  - `ART_CHAR_107_v01_韩启程_角色五视图.png`

  四人共同画风锚点为主角 `ART_CHAR_001_v02`；历史群像 `ART_CHAR_002_v01_四位NPC侧影.png` 保留不删。
  四张图都只有「头肩头像 + 正/左/右/背」五个视角，没有动作帧，**不得**裁切后冒充动画或直接入库。
- 本目录内容**不会**被 Godot 导入；正式 sprite sheet 要另行制作并放进 `assets/characters/`。
