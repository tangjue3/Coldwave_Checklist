# 《寒潮清单》第一季剧情

请阅读 [第一季完整剧本](第一季完整剧本.md)。剧本包含女主重生后绑定的寒潮生存系统、16 项任务及具体奖励、梧桐里社区和居民群像、逐日主线、分镜、对白、分支、16 个支线及四种结局。

制作横向场景时，参阅 [第一季横版场景设计与提示词](../../02-场景/第一季横版场景设计与提示词.md)，其中列出地图连接、各地点的横向分段、天气状态和提示词。

剧本中的事件 ID 和状态名供后续开发查找使用；剧情和数值目前仍是策划资料。涉及订单、行动点、设施与演示范围的待确认问题，见[冲突清单与建议](../../../../docs/v1.1_冲突清单与建议.md)。
