## 视觉方向

2D 正侧视 / 建筑正剖面；偏写实的正常人物比例；精细手工像素、清晰深色轮廓；
低饱和灰棕 / 暗绿 / 烟蓝；室外极寒蓝灰与室内暖黄灯光强对比。
不是 Q 版、不是 8-bit 大块色、不是 3D 渲染、不是高清二次元立绘。

## 尺寸基线

- 内部视口 960×540，整数倍缩放、Nearest 采样（已在 `project.godot` 验证）
- 世界 tile 暂定 32×32；主角单帧试稿约 96×192
- UI 图标建议 24 / 32 / 48 px 三档
- 所有素材必须统一像素密度，禁止把高清图简单缩小混用
