# 10 · 暂停与设置

`Esc` 暂停菜单与音量 / 显示 / 操作 / 退出设置。

## 放什么

- 暂停遮罩与菜单（继续 / 设置 / 返回主菜单 / 退出）
- 设置分组：音量（主音量、音乐、音效）、显示（窗口 / 全屏 / 缩放）、操作（键位列表）
- 控件外观：滑块、开关、下拉框、单选、键位按钮
- 二次确认框（"退出会丢失未保存进度"）

## 出图要点

- 暂停是**模态**：遮罩要压暗背景但不完全遮死，alpha 建议 60–75%。
- 滑块、开关、下拉框当前主题**完全没有覆盖**，会露出 Godot 默认灰白皮肤，这几件必须成套出。
- 键位按钮要能显示"A""←"这类单字符，按钮宽度按最长键名（"Space""Escape"）留。
- 设置项文字是可变量，标签区留空槽。

## 编号与对位

- 遮罩、暂停面板、各控件各自领号；控件优先放 `11-通用UI组件/` 出一次再复用。
- 全屏 / 窗口切换目前游戏里还没有实现，UI 可以先出，但别在图上写死"按 F11"。
