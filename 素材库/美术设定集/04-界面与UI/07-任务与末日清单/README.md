# 07 · 任务与末日清单

末日倒计时清单、任务列表、勾选状态与事件通知。

## 放什么

- 末日清单纸底（米白纸纹 + 打孔 / 折痕 / 手写感）
- 待办行：勾选框、条目名、期限、完成态划线
- 倒计时条：D-7 → D0 → D+7
- 任务列表与详情：目标、奖励、状态
- 事件通知条（"邻居来敲门""暴雪预警"）

## 出图要点

- 风格锚点来自 v1.1 规范：**米白清单纸纹理 + 暖黄数值**。纸纹要能平铺或九宫格拉伸，别画成一张固定尺寸的死图。
- 勾选框给空 / 半勾 / 完成三态，尺寸不小于 16×16。
- 条目文字是可变量，纸底不要预留固定文字的凹槽。
- 完成态划线用整像素直线，不要抗锯齿斜线。

## 编号与对位

- 清单纸底、勾选框、倒计时条各自领号。
- 手写体若要用字体实现，走 `assets/ui/fonts/` 流程；本目录只放图形素材。
