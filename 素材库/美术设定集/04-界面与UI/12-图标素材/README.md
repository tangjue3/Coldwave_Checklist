# 12 · 图标素材

界面用的功能图标与图集。

## 放什么

v1.1 规范点名约 **16 枚**：现金、AP、食物、水、燃油、电量、抗寒、生命、交易、拆装、旋转、地图、消息、温度、存档、时间。

外加少量状态图标：警告、锁定、已装备、可交互。

## 出图要点

- **走图集**：16 枚画进一张 atlas（建议 16×16 或 24×24 单格，按 4×4 或 8×2 排），**整张算 1 个 `ART_UI_` 号**，单枚不单独领号。
- 单格尺寸统一，四周留 1–2px 安全边，避免切片时被邻格吃掉。
- 纯白 / 纯色描边要能靠 `modulate` 变色，否则每换一种状态就得多画一张。
- 同一张图集里风格必须一致：线宽、圆角、留白比例统一，别混线性和填充两种画法。
- 交付时附切片坐标表（或写进 `AtlasTexture` 配置说明），否则程序只能猜。

## 编号与对位

- 图集 1 个号；若某类图标数量多到需要拆第二张，第二张另领号并在台账注明"图集之二"。
- 物品本体图标（水瓶、纸箱）不在这里，归 `03-物品与家具/`。
