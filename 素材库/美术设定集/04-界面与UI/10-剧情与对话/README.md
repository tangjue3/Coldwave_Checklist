# 10 · 剧情与对话

底部对话栏、角色名条、选项按钮，以及人物身边的短句气泡。

## 放什么

- 底部对话栏（九宫格）：说话人行、正文区、继续指示
- 角色名条 / 名字签（可换色区分主角与 NPC）
- 选项按钮（GDD 要求三选项），含悬停与选中态
- 人物气泡短句（小人头顶的小框）
- 旁白 / 内心独白 的差异化样式

## 出图要点

- 正文区要能放 **2–3 行中文而不挤**：960×540 下正文建议 ≥ 14px 字号，先算字数再定框高。
- 名字条宽度要能容下最长人名（如"孟雨薇""韩启程"），留出余量。
- 气泡框与小箭头分开出，箭头方向（左上 / 右上）各一张，别用旋转凑。
- 半透明对话栏注明底色与 alpha；不要烘焙投影。

## 编号与对位

- 对话栏、名字条、选项按钮、气泡各自领号。
- `ART_UI_003`（对话框 / 角色名）是 v1.1 预留位，资产真正入库时才裁定改为「已用」。
- 角色立绘 / 头像归 `assets/portraits/`（当前为空），不在本目录。
