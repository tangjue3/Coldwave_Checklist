# 13 · 动效与反馈

界面动效的分镜、序列帧，以及各类操作反馈态。

## 放什么

- 面板进出：淡入 / 滑入 / 缩放
- Toast 进出与停留
- 数值飘字（+1 食物、-3 AP）
- 警示反馈：资源告急闪烁、暴雪预警脉冲、非法落位抖动
- 箭头指引 / 高亮呼吸（新手引导用）
- 转场（场景切换目前是硬切，没有过渡）

## 出图要点

- 序列帧按 `名称_序号.png` 命名，尺寸全场统一，写明帧数与建议 FPS。
- 动效分镜图（一张里画多帧）属于**概念稿**，不能直接进引擎；要能用就得给逐帧 PNG。
- 纯代码能实现的（透明度、位移、缩放、缩放曲线）**优先用 Tween 实现**，不必出图。这里只放"必须靠贴图"的部分。
- 闪烁类效果给出周期与幅度，不要只写"闪一下"。

## 编号与对位

- 一段动效算 1 个号（序列帧作为该行的 `动画帧序列` 归属，不单独领号）。
- 帧文件放本目录下按动效命名的子文件夹，台账用 glob 描述，不要逐帧登记。
