# 12 · 通用 UI 组件

能被多处复用的底板、按钮、滚动条、页签、提示框与 Toast。**先在这里出一次，别在各功能目录重复画。**

## 放什么

- 面板底板九宫格：深色主面板 / 浅色清单纸 / 半透明浮层
- 按钮：主按钮 / 次按钮 / 图标按钮，各 4 态（normal / hover / pressed / disabled）
- 页签：未选 / 悬停 / 选中 / 禁用
- 滚动条：轨道、滑块、两端箭头
- 提示框：确认框、错误框、信息框（含图标位）
- Toast：底板、进出动效的起始态
- 分割线、描边角标、焦点框

## 出图要点

- 每件都要给九宫格边距；按钮另给四态的行高与 y 偏移。
- 尺寸取整像素，同一组件系列的内边距保持一致（建议 4 / 8 / 12 三档）。
- **不要**把阴影、发光烘焙进底板；需要时单独出一层。
- 现有主题是"深灰面板 + 琥珀描边 + 4px 圆角"，新组件要与它同族，否则运行时会两套风格打架。

## 编号与对位

- 一个组件（含其四态）算 1 个号；不要把四态拆成四个号。
- 运行时对应 `StyleBoxFlat` / `StyleBoxTexture`，交付时注明"哪几块用九宫格、圆角半径、描边宽度"。
