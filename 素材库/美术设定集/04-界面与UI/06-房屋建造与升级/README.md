# 06 · 房屋建造与升级

`B` 进入的建造模式：网格、落位高亮、设施信息、房间升级前后对比。

## 放什么

- 半透明建造网格（32×32 世界格对齐）
- 合法 / 非法落位框（绿 / 红），以及旋转态、拆除态
- 设施信息卡：名称、耗电、占用、安装 AP
- 房间升级前后的状态对照（如安全屋 v01-base → v01-upgraded）

## 出图要点

- 网格一格必须正好等于世界 32 px 在屏幕上的显示尺寸，**先确认相机缩放再定像素**，否则网格与场景对不上。
- 半透明层单独出图并注明 alpha；不要把它烘焙进房间背景。
- 合法 / 非法不能只靠颜色区分，要有形状或图标差异（GDD §8.1 的色盲要求）。
- 升级对照图属于**设计参考**，实际升级靠设施实例与房间状态，不靠整图切换。

## 编号与对位

- `ART_UI_002`（建造模式）是 v1.1 预留位，资产真正入库时才裁定改为「已用」；其余从下一可用号顺延。
- 落位框四态可以画在同一张，但必须写明各态的位置偏移。
