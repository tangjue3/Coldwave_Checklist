# 04 · 背包与物资

`Tab` 打开的清单 / 背包：格子、物品卡、分类页签、容量。

## 现在有什么

`候选-v01/` = 美术总监交付的《背包与物资 UI 独立透明素材包 v01》（TASK-UI-010 归档）：
6 面板 + 5 格态 + 7 按钮/分类态 + 12 图标 = **30 文件 / 21 个号 `ART_UI_043`–`063`**，
**全部「待审核」**，只用于 `scenes/dev/inventory_preview.tscn`。
尺寸是逻辑 1:1（不是 2 倍图），九宫格边距见包内 `manifest.json` 与 `README_素材包说明.md`。

> 交付包的 `05-预览/` 与 `06-参考资料/` 不在这里，另存 `转存库/背包素材包v01_预览/`；
> 那两张含烘焙文字，禁止当运行时贴图。

## 放什么

- 背包主面板底板（九宫格）与格子阵列
- 物品卡：图标、名称、数量、简述
- 分类页签：食品 / 饮水 / 燃料 / 电力 / 药品 / 工具 / 其他
- 格子状态：空 / 已占用 / 选中 / 拖拽中 / 不可放置
- 容量条与超载提示

## 出图要点

- 格子尺寸取整数、内边距固定，方便程序排版。**v01 交付的是 58×58**（不是 32 的倍数），
  按 1:1 直接用，不缩放；这是本批的既定尺寸，后续版本若要改须整包重出。
- 物品图标与格子底图分开出，不要焊在一起。
- 一屏能放几格要先算：960×540 扣掉 HUD 与页签后剩下的区域，别画完才发现放不下。

## 编号与对位

- 面板底板、格子、页签各自领号（能独立拉伸 / 独立引用的才算一个）。
- 物品图标不属于本目录，归 `03-物品与家具/`；这里只放"装物品的容器"。
- v01 预览里的食物 / 饮水 / 木材 / 布料 / 手电筒 / 钳子 / 钥匙图标**直接复用已批准的
  `assets/ui/hud/v01/HUD_icon_*`**，没有复制进来、也没有重新领号。
