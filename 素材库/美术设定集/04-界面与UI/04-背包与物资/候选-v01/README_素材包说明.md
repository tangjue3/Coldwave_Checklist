## 尺寸

**这批是逻辑尺寸 1:1，不是 2 倍图**（与 HUD v01 包不同）。文件名里的 `_宽x高` 就是运行时尺寸，
可以直接按原尺寸摆放，不需要缩放到 0.5×。

面板：主窗 760×430、详情 194×310、分类 138×302、弹窗 350×248、Tooltip 256×156、搜索框 195×36。

## 复用既有 HUD 图标

食物、饮水、木材、布料、手电筒、钳子、钥匙、现金**直接引用已批准的 `assets/ui/hud/v01/HUD_icon_*`**，
没有复制成新 ID——按交付说明不该重复登记。

## 导入规则

- 运行时副本 `assets/ui/inventory/v01/`，保留原英文文件名。
- `.import`：`fix_alpha_border=false`、`detect_3d/compress_to=0`、无损、`mipmaps/generate=true`；
  节点侧 `texture_filter = 3`。全局仍是 Nearest，不改。
- 两张图的最大 alpha 不到 255（`button_disabled` 127、`slot_drag` 147），这是美术有意的半透，
  不要当缺陷修。
