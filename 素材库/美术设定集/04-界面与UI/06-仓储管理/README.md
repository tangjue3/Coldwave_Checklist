# 06 · 仓储管理

家里仓储的分类、堆叠、容量与出入库界面。

## 放什么

- 仓储主面板：分类页签（与背包一致）、堆叠列表、容量条
- 堆叠卡：物资图标 + 数量 + 单位
- 出入库操作：取出 / 放入 / 全部取出
- 满仓、超载、分类为空的空态

## 出图要点

- 分类页签的用词与图标必须和背包（`04-背包与物资/`）**完全一致**，不要各画一套。
- 堆叠数量可能到三位数，数字区留够宽度。
- 空态要单独出图（"这一格还没有东西"），别让程序拿空字符串凑。

## 编号与对位

- 面板底板、页签、容量条各自领号。
- 与背包共用组件时，**优先在 `12-通用UI组件/` 出一次**，两处引用同一张，不要重复画。
