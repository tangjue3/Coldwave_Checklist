# 02 · 字体

`ART_UI_` 号段。存放**字体选型、字形对照、排版规格**这类"看起来像界面的字"的资料。

> 目录在 2026-11-12（TASK-UI-004）新建，原 `02-游戏HUD` 及之后全部分类顺延一位。

## 放什么

- 字体样张、字形对照图（同一句话在不同字体下的并排对比）。
- 字号 / 字重 / 行高 / 字距的排版规格图，带标注的那种。
- 描边、阴影、发光等文字效果的参数示意。
- 字体的授权文件副本（正本在 `assets/ui/fonts/`，这里只放"给人看"的一份）。

## 不放什么

- **不放能直接进引擎的字体文件**（`.ttf` / `.otf`）。运行时字体只认 `assets/ui/fonts/`，
  本目录被 `.gdignore` 隔离，放进来引擎也读不到。
- 不放把文字烘焙成 PNG 的界面图。本工程的 HUD 文字一律是**真文本 + LabelSettings** 渲染，
  不把动态文字做成图片（改了要重画，而且缩放会糊）。
- 不放 `03-游戏HUD/` 里的面板、图标——那些是容器和符号，这里只管字。

## 当前结论（2026-11-12 实测）

| 用途 | 字体 | 资源 |
|---|---|---|
| 正文、状态标签、按钮 | 思源宋体 400 | `assets/ui/fonts/NotoSerifSC-Regular.ttf` |
| 面板标题、数值、栏目标签 | 思源宋体 600 | `assets/ui/fonts/NotoSerifSC-SemiBold.ttf` |
| 任务清单、剧情对白、手写感标题 | 霞鹜文楷 Screen 400 | `assets/ui/fonts/LXGWWenKaiScreen.ttf` |

依据：ChatGPT 的概念图里，面板与数值是**宋体**（横细竖粗、有明显顿角），标题带**手写笔势**，
宋体做不出来，用霞鹜文楷替代最接近。两种字体分工明确——宋体读"信息"，楷体读"人写的东西"。

字号（概念图 1672×941 换算到本工程 960×540，×0.574 后再按可读性微调）：
正文 12–17、面板标题 21、画面标题 28。完整清单见 `assets/ui/labelsettings/README.md`。

## 已知坑：可变字体在 Godot 4.7.2 上不生效

思源宋体官方提供单文件可变字体（`wght` 200–900，25 MB）。实测 `FontVariation` 的
`variation_opentype` 对它**完全不生效**：200 / 400 / 600 / 900 渲染结果像素级相同。
所以最终交付的是三个静态实例（400 / 600 / 900，各 14.8 MB）。细节与复现方式见
`assets/ui/fonts/README.md`。

**这条要记着**：以后看到"用可变字体省体积"的建议，先在本工程跑一遍墨迹对比再决定。

## 命名

沿用全库格式，字体样张这类"给人看的图"用 `v` 版本：

```text
ART_UI_<三位序号>_<v|r><两位版本>_<中文短名>_<宽x高>.png
```

字体文件本身**不占 `ART_UI_` 号**——它们不是美术素材而是运行时资源，走 `assets/ui/fonts/`
自己的 README 与 SHA256 记录，不登记素材台账。
