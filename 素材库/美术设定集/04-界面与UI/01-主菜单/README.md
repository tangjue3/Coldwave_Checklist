# 01 · 主菜单

游戏启动后的第一屏：标题画面、按钮组、版本行。

## 放什么

- 主视觉 / 标题 LOGO（可分图层出：底图、标题字、装饰）
- 按钮组：新游戏 / 继续游戏 / 设置 / 退出（现有实现另有「开发测试入口」，正式版要不要保留待定）
- 底部版本行、版权与授权声明行
- 有「继续游戏」禁用态、无存档时的提示态

## 出图要点

- 整屏 960×540，背景与框体分层出图，不要和按钮焊死在一张图里。
- 按钮必须给 `normal / hover / pressed / disabled` 四态，并注明九宫格边距。
- 标题若是像素字，按整像素阶梯出图；若是手写体，另附切好的 PNG，不要只给整幅设计稿。

## 编号与对位

- 整屏设计稿领 1 个 `ART_UI_` 号；拆成按钮、LOGO 等可独立引用的零件时各自领号。
- 运行时位置参考 `scenes/menu/main_menu.tscn`（标题 y≈58–122、按钮列 350–610、页脚 502）。
