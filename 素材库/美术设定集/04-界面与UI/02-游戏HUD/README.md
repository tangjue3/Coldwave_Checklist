# 02 · 游戏 HUD

游戏进行中的常驻界面：日期、天气预警、AP、现金、食物 / 水 / 燃料 / 电力 / 抗寒，以及交互提示条。

## 放什么

- 顶部常驻条：日期、天气预警、AP、现金
- 侧边或快捷栏：采购清单入口、手机消息入口
- 资源区：食物、水、燃料、电力、抗寒（数值 + 图标）
- 底部：交互提示、人物状态
- 状态态：资源告急、暴雪预警、AP 耗尽

## 出图要点

- 布局依据 `docs/handover_v1.0/01_GDD_玩法美术与数值.md` §8.2；960×540 下信息密度很高，**先定"哪些常驻、哪些收起"再画**。
- 数值区要给"纯数字可替换"的空槽，数字不要烘焙进底图。
- 告急态不能只靠红绿：红字要配警告图标，资源始终显示数值（色盲与低分辨率要求，GDD §8.1）。
- 面板走九宫格；半透明底板注明底色与 alpha。

## 编号与对位

- HUD 是系统而非单个零件：整屏布局稿领 1 个号，拆出的独立零件（顶栏底板、资源条、图标）各自领号。
- `ART_UI_001`（HUD 与购物车）是 v1.1 的预留位，只有该资产真正入库时才由美术总监裁定改为「已用」。
