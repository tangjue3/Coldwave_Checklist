# 08 · 地图与导航

场景导航图、区域缩略与当前位置标记。

## 放什么

- 梧桐里长街缩略图（全长 25,095 px → 缩略比例待定）
- 区域分块：家门段 / 商业街段 / 批发仓段
- 门点图标（12 处室内入口）、当前所在位置标记
- 已探索 / 未探索 / 暂不可进入 三种状态

## 出图要点

- 地图是先缩后画还是先画后缩要先定：**建议按 1:1 画关键地标，再用整数比例缩略**，避免缩完地标糊成一团。
- 缩略图的坐标要能和世界 X 换算（给出比例与零点），否则程序没法把"当前位置"点上去。
- 门点图标不超过 16×16，且与 `12-图标素材/` 里的同类图标风格一致。

## 编号与对位

- 长街缩略、区域块、门点图标、位置标记各自领号。
- 地图只画**已存在**的场景：第一季 13 个正式美术场景 + 后续要补的，未做的不要先画上去当承诺。
