# 03 · 背包与物资

`Tab` 打开的清单 / 背包：格子、物品卡、分类页签、容量。

## 放什么

- 背包主面板底板（九宫格）与格子阵列
- 物品卡：图标、名称、数量、简述
- 分类页签：食品 / 饮水 / 燃料 / 电力 / 药品 / 工具 / 其他
- 格子状态：空 / 已占用 / 选中 / 拖拽中 / 不可放置
- 容量条与超载提示

## 出图要点

- 格子尺寸取整数（建议 32 的整数倍，与场景物资 32×32 图标对齐），格子内边距固定，方便程序排版。
- 物品图标与格子底图分开出，不要焊在一起。
- 一屏能放几格要先算：960×540 扣掉 HUD 与页签后剩下的区域，别画完才发现放不下。

## 编号与对位

- 面板底板、格子、页签各自领号（能独立拉伸 / 独立引用的才算一个）。
- 物品图标不属于本目录，归 `03-物品与家具/`；这里只放"装物品的容器"。
