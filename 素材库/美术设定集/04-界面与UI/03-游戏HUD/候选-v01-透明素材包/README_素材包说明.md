## 尺寸

所有 PNG 都是实际像素的 2 倍，**按 `manifest.json` 的 `logical_size` 在 960×540 里显示**（即 0.5×）。
文件名里的 `_宽x高` 写的是**真实像素**，不是逻辑尺寸。

面板在逻辑尺寸下的实际大小：地点 216×35、时间 136×35、天气 130×35、今日清单 216×152、
生存状态 216×164、资源 242×35、交互 178×35、Toast 272×50、Tooltip 184×72。

## 导入规则

- 运行时副本在 `assets/ui/hud/candidates_v01/`，保留原英文文件名。
- `.import`：`fix_alpha_border=false`、`detect_3d/compress_to=0`、无损压缩、`mipmaps/generate=true`；
  节点侧 `texture_filter = 3`（LINEAR_WITH_MIPMAPS）。**不要动全局 Nearest 设置**——角色像素精灵还要用。
- 这批图是手绘 UI，缩放优先用本包对应尺寸的面板；确需九宫格拉伸时先实测边距再记录。
