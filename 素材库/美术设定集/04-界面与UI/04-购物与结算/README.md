# 04 · 购物与结算

商店里的商品卡、价格牌、购物车清单与收银结算界面。

## 放什么

- 货架商品卡：图标、单价、库存、限购标记
- 价格牌 / 涨价标记 / 缺货标记
- 购物车清单：已选物品、数量加减、小计与总计
- 结算面板：付款、找零、容量超限提示
- 购物车容量条（与 `ART_FURN_103` 的 EMPTY / HALF / FULL 三态呼应）

## 出图要点

- 数量加减按钮给 4 态，最小可点区域不小于 24×24（960×540 下手指/鼠标都够得到）。
- 金额、数量是变量，必须留空槽由程序填，不要画成固定数字。
- 结算确认与"买不起 / 装不下"的失败反馈要成套出，别只画成功路径。
- 购物车容量三态是**视觉**，实际容量由数据决定，图里不要写死格数。

## 编号与对位

- 商品卡、结算面板、容量条各自领号；整屏布局稿另领 1 个号。
- 商品图标来自 `03-物品与家具/`，本目录只管卡片与框架。
