# 《寒潮清单》ART-DESIGN-004｜购物物资与家具首批样本

## 本批目标

把「囤货越来越满」从抽象数值转化为能被玩家直观看见的房间变化，同时试制几件**独立透明背景的游戏物件候选图**。这是美术概念和资源管线试样，尚未通过 Godot 运行时像素尺寸、碰撞框、交互或动画验收。

美术风格锚点：`ART_CHAR_001_v02`（许知夏）、`ART_SCENE_102_v01`（安全屋升级态）、v1.1 十二物资概念图。统一成熟的 2D 横版、低饱和灰棕/烟蓝/旧绿、暖光与深炭灰轮廓。

## 资产审核结论

五张图适合**美术设定库**浏览和作为正式像素精修参考。

- 已确认四张独立候选 PNG 具有真实 alpha 通道，存在透明区域。
- alpha 里存在半透明边缘和视觉阴影，不能仅因为是 RGBA 就标成「运行时可用」。
- 原图尺寸远大于预期游戏物件大小；不可直接在 Godot 中对高清图使用任意平滑缩小后就声称达到统一像素密度。
- 目前没有验证小像素尺寸下文字状图案的可读性和边缘一致性，后续必须进行像素清理或重绘。
- 货架三阶段图只用于表达数量增加的视觉目标，后续不能假装更新一个背景贴图就等于实现背包/库存系统。

## 世界尺寸建议（待引擎实际验收）

参考内部画面 `960×540` 与暂定 `32×32` world tile，先采用以下**起始试稿目标**。正式大小由真实游戏角色高度、交互距离、商品摆放密度试测确认。

| 对象 | 建议像素画布 | 参照用途 |
|---|---|---|
| 一组六瓶水 | 约 `64×48` px | 货架物件和少量堆叠 |
| 食品纸箱 | 约 `64×64` px | 地面可搬动、可叠放物资 |
| 四层储物货架 | 约 `96×192` px | 3 tile 宽、6 tile 高的初始模块 |
| 电暖器 | 约 `64×96` px | 地面取暖设施 |

统一底部定位锚点（bottom center），每物体保留清晰可读轮廓，禁止随意的半像素移动与模糊滤镜；碰撞与交互热区须由工程实际定。

## 核心游戏反馈设计

1. 玩家采购的水、食品、药品和毛毯进入真实库存清单。
2. 放进安全屋货架后，对应物品随数量增加逐步出现在架子上。
3. 货架不是「空/满」的纯装饰图，要有与存储占比和物品类别相关的可见变化。
4. 建议 MVP 先做 `empty / half / full` 三档的组合效果；需要时再细分多个层格和类别。
5. 货架主体与堆放的物品应为可独立组合的图层，避免同一物件在「半满」状态突然变形或改变货架结构。
6. 暖器应有 `off / on` 状态；亮度能体现通电与否，但不能表现成明火或燃油室内燃烧。

## 统一生成提示词摘要

Handcrafted crisp 2D orthographic game pixel art, no isometric view, deeply muted charcoal / smoke brown / slate blue palette, realistic worn physical materials, readable at low pixel resolution. For individual items: single centered isolated object with genuine transparent alpha, no stage, no cast shadow, no labels or logos. For the stockpile sheet: three aligned instances of the EXACT same four-tier shelf, changing only quantity and category of stored goods (nearly empty, half full, nearly full).
