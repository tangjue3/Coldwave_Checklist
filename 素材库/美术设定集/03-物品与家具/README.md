约定：

- **`ART_FURN_101` 的两张图是同一设施的两种展示状态**（空载本体 / 三阶段装载对照），
  靠版本列区分，**不是两个家具 ID**。禁止在代码或数据里拆成两个设施。
- 「囤货三阶段」是**视觉验收基准**，不是库存系统。实现必须是库存数据 + 可独立组合的图层，
  不允许整图切换冒充；货架主体与堆放物分层，半满状态不得让货架变形。
- 四张透明候选虽有真 alpha，但**含半透明边缘与视觉阴影**，原图也远大于目标尺寸，
  不能因为「是 RGBA」就标运行时可用。进 `assets/` 前必须做像素清理或重绘。
- 锚点统一底部中心（bottom center），禁止半像素位移与模糊滤镜；碰撞与交互热区由工程实际定。
- 电暖器本图是**通电状态**：橙红来自电热元件，不得表现成明火或燃油室内燃烧；正式实现需补 off / on 两态。
