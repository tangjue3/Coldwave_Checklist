### 商品图对应关系错误（2026-11-09 已修正，ART-FIX-003C）

原 ART-RUNTIME-003C 交付的**四张商品图内容与 ID 全部互换**，不只是 32×32：

| 文件 | 标称 | 实际画的是 | 现状态 |
|---|---|---|---|
| `ART_ITEM_101_r01_water_64x48.png` | 饮用水 64×48 | 食品纸箱 | 不予通过（保留追溯） |
| `ART_ITEM_101_r01_water_shelf_32x32.png` | 饮用水 32×32 | 食品纸箱 | 不予通过（保留追溯） |
| `ART_ITEM_102_r01_food_carton_64x64.png` | 食品纸箱 64×64 | 六瓶装水 | 不予通过（保留追溯） |
| `ART_ITEM_102_r01_food_shelf_32x32.png` | 食品纸箱 32×32 | 六瓶装水 | 不予通过（保留追溯） |

**为什么当时没查出来**：这四张的尺寸、alpha 档位、脚底锚点全部合格，像素合同检查逐项通过；
错的只有"画的是什么东西"。ART-INTEGRATE-003 时只靠目视在货架截图里发现错位，且当时误判为
"只有 32×32 互换"，实际 64 版也一起错了。

**现在的防护**：`scripts/dev/art003_verify.gd` 的 `[A2]` 组按"不透明像素平均色"判归属——
水偏蓝灰（蓝−红 ≈ +36），纸箱偏暖棕（红−蓝 ≈ +83），两者互斥，不可能同时成立。
把 `WATER_TEX` 故意指回 r01 错误文件时，该组会明确报 `内容=食品纸箱` 并判失败，
而像素合同那一组仍然全绿——这就是当初漏检的复现。

正确版本是 `r02` / `r02-shelf` 四张，见上表同名 r02 行。

### 货架实测尺寸（勘误）

货架实测**内宽 90、层高 34–35**（先前按概念图估的 84 / 37 偏乐观）：32×32 能上架（头顶余 2–3px），
48 高的大包装只能落地。**不要为了塞进层板而缩放商品**——层高不足就该落地。
