## 为什么不登记 ID

素材库的唯一键是 `素材 ID + 版本`，一个 ID 对应一组「同一件东西的不同版本」。
验收对照图既不是新东西，也不是某件东西的新版本，它是**多件素材的组合快照**；
给它编号会污染号段，也会让人误以为它是可引用素材。

## 规则

- 文件名**不得**以 `ART_<类别>_<三位序号>_` 开头（会被 `tools/check_id_registry.py`
  当成占用编号）。本目录两个文件用 `ART-RUNTIME-` / `ART_ITEM_101_102_` 形态，不含独立 ID。
- 不得被 `assets/` 引用，不得进 `美术总览.html` 的素材网格（它会作为「验收证据」单独列出）。
- 本目录内容可删除重建，不属于需要长期保存的原始资产。
