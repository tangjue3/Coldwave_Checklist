# 02 · 场景

**室外和室内彻底分开**：

- `01-建筑/` —— 只放室外正立面，一栋建筑一个文件夹，里面就 `室外.txt` + 出好的图
- `02-室内/` —— 只放室内剖面，文件夹名和 `01-建筑/` 里的完全一致，里面就 `室内.txt` + 出好的图

整条街不用单独出图——每栋楼各出一张室外图，按 `season1_map.tscn` 里的站位摆进去就是一条街。

## 怎么用

1. 进 `01-建筑/02_AB_外婆小楼/`，开 `室外.txt`，正文整段复制，生成这栋楼的外观
2. 出的图存成 txt 第二行的文件名，放回这个文件夹
3. 再把这张室外图当**参考图**，进 `02-室内/02_AB_外婆小楼/` 开 `室内.txt`，整段复制，生成室内
4. 图按 txt 第三行的尺寸缩好，放回 `02-室内/` 那个文件夹

每个 txt 只有 3 行表头 + 一段话，正文那一整段全选复制即可：

```
A/B · 外婆旧两层小楼
A_EXT_1575x680_v01.png
世界尺寸 1575 × 680

原创 2D 横版生存经营游戏场景，正侧视……一栋老式两层临街小楼的正立面……画面里不要出现：俯视、鸟瞰……
```

每个 `室内.txt` 的第二句就是**参考图指令**：以 `01-建筑` 下同名文件夹里 `室外.txt` 出的那张图为参考，沿用墙体材质、门窗横向位置、层高与光线方向，并声明室内宽度等于该建筑的室外宽度。生成时把室外图一起丢给模型、正文整段复制即可，不用自己补话。

## 室内怎么进

游戏里的流程：人物在室外走到门口 → 按 `E` 交互 → 切到室内场景；室内走到门边按 `E` 回到街上，并回到进来时那扇门的位置。

所以室内图要满足：

- **宽度 = 这栋楼的室外宽度**（清单里写死了，例如小楼 1575、超市 1800），这样人物推门进去的落点和门洞位置能对上
- **一层地面在图的底部**，进门后人物就站在门内侧
- 门洞在室内图里的横向位置，要和室外立面上那扇门的位置一致（居中或偏左偏右，看各楼）
- 招牌、价签、货物留空，不烘焙进背景

等室内图到位，接场景时按「门 → 室内场景」建一个交互热点，走 `SceneRouter.goto()`，并记录返回落点。

## 尺寸怎么用

文件名里的宽×高就是这张图在游戏世界里占的像素。缩到这个尺寸拖进 Godot，`scale=1` 正好落位。

- 人物 160 px，住宅门 96×192，超市门 192×224，层高 312
- 地面线在世界 y=0，画面高度 72% 处
- 全街长 25,095 px，每栋楼在街上的位置、宽度、高度都写在 `scenes/world/season1_map.tscn` 里
