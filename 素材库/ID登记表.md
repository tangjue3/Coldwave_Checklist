# 素材 ID 登记表（正式登记）

> 本文件由 `python tools/check_id_registry.py` 从 `素材库/ID登记表.csv` 生成，**不要手改**。
> CSV 是唯一来源；台账 `素材库/素材台账.csv` 与磁盘文件名都必须服从它。
> 命名与旧 ID 映射的历史理由见 `素材库/ID对照表.md`。

## 1. 号段规则

| 号段 | 规则 |
|---|---|
| `001–099` | 首批归档与合集条目，不再扩号；合集不拆、不删、不覆盖 |
| `101–199` | 后续个体条目与规划预留；新条目从「下一可用号」起，不得回填空置位 |

文件与条目的命名：`ART_<类别>_<三位序号>_v<两位版本>_<中文短名>.<扩展名>`；

- 版本序列：`v01` 起为**设定 / 概念版本**；`r01` 起为**运行时候选 / 运行时版本**（美术交付包使用 `r`）。
- 两者都可带状态后缀，例如 `v01-base`、`v01-upgraded`、`v01-empty`、`v01-stages`。
- 状态后缀不写进文件名，文件名只用基础版本号（`..._v01_...png`）。

## 6. 入库前必须走的四步

1. **查号**：在本表里搜素材内容，确认它是不是已有条目；已有就补版本，不再新开号。
2. **定号**：确实要新开条目时，用对应前缀的「下一可用号」，从高位顺延；
   **不得**回填空置位，**不得**占用预留位。
3. **登记**：先在 `素材库/ID登记表.csv` 增加一行（状态写 `已用`），再动文件与台账。
4. **校验**：运行 `python tools/check_id_registry.py`，必须全绿再提交。

> 交付包（ART-DESIGN-00x）若自带编号，先按上述四步比对：
> 与预留号冲突时，以「不推翻既有裁定」为前提二选一——让位方顺延，或交付包改号，
> 两者都要在 `素材库/ID对照表.md` 的修订记录里写清理由。
