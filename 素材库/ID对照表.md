# 素材 ID 对照表（ARTLIB-001）

> 目的：解决 `docs/v1.1_冲突清单与建议.md` 的 **C1：素材 ID 与剧情事件 ID 撞名**。
> 本轮只建立对照与修订版文档，**没有创建任何新的美术文件，也没有改动游戏代码或 `data/`**。

## 1. 新命名规则

| 前缀 | 含义 | 目标目录 |
|---|---|---|
| `ART_CHAR_` | 角色 | `美术设定集/01-角色/` |
| `ART_SCENE_` | 场景 | `美术设定集/02-场景/` |
| `ART_ITEM_` | 物品 | `美术设定集/03-物品与家具/` |
| `ART_FURN_` | 家具设施 | `美术设定集/03-物品与家具/` |
| `ART_UI_` | 界面 | `美术设定集/04-界面/` |
| `ART_FX_` | 特效与动画 | `美术设定集/05-特效与动画/` |

完整文件名：`ART_<类别>_<三位序号>_v<两位版本>_<中文短名>.<扩展名>`。
`001–099` 用于**已实际归档的资料**；`101+` 用于**规划中、尚未制作**的条目，避免两者抢号。
版本递增另起一行台账，旧版本不覆盖、不删除。

## 2. 剧情事件 ID 一律不变

`P00..P07`、`D00..D07`、`S01..S16`、`PxxB` / `DxxB` 以及四个结局 ID 保持 v1.0 / v1.1 剧本原样。
本次只给**美术素材**换 ID，剧情逻辑编号、flag、`seen_events` 去重键都不受影响。
修复撞名的方式是让美术侧退出 `Snn` 命名空间，而不是改剧情。

## 6. 使用约定

- **编号以 `素材库/ID登记表.csv` 为准**（SCALE-001 起）。本表记录的是**历史映射与裁定理由**，
  登记表记录的是**当前每个号的状态**；两者冲突时以登记表为准，并回头补本表。
  新增素材前先查 `素材库/ID登记表.md` 的「下一可用号」，再运行 `python tools/check_id_registry.py`。

- 讨论美术时只说 `ART_*`；讨论剧情时只说 `P/D/S/B` 系列，两者不会再用同一个编号。
- 台账里 **`素材ID` + `当前版本` 才是唯一键**：同一素材的多个版本共用 ID，靠版本区分（例如 `ART_CHAR_001` 的 v01 历史备选与 v02 外观基准并存）。预览页按本表展示旧 ID 作为「来源 ID」备注。
- **建设状态也写在版本列里**，例如安全屋的两张图分别是 `ART_SCENE_102` 的 `v01-base` 与 `v01-upgraded`。
  它们是**同一场景的两个状态**，不是两个场景、也不是版本迭代；一个文件一条台账，靠版本列保持唯一键，
  但游戏里必须由设施实例 / 房间状态驱动，不能靠切换整张背景图实现。
