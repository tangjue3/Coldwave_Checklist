# 末日囤货建设 · 室外长街填充素材 v01

本包对应用户提供的 10 份提示词及《放置计划.txt》，用于 Godot 4.7.2 的 2D 横版室外长街补景。所有可直接使用的图片放在 `assets/`，全部为带透明通道的 RGBA PNG，画布尺寸与文件名内世界像素完全一致。导入时 `scale=(1,1)`，默认以图片**底边**对齐地面线。

## 目录

- `assets/`：正式尺寸的 10 件 PNG，供场景 Agent 引用。
- `source_imagegen/`：9 件 AI 原图（保留原始尺寸，便于后续迭代）。
- `source_vector/`：架空线的可编辑 SVG，5 条 1–2 px 周期曲线。
- `prompts/`：10 份原提示词，以及用户提供的《放置计划》。
- `preview/10件填充素材总览.png`：便于审核的总览，底色仅用于预览，**未写入素材图**。

## 工程注意事项与验收

1. 所有 PNG 已检验尺寸和 RGBA 透明通道；均为静态 2D 视觉资源，没有烘焙角色、碰撞或 UI。
2. `围墙` 与 `栏杆` 在 v01 中使用左右镜像单元，确保**最左、最右像素列可以对齐**。这会带来左右材质对称的观感，若后续追求自然变化，可在场景里增加局部污渍贴花、遮挡与翻转，不建议任意拉伸。
3. `架空线` 为精确绘制的 5 根纤细周期曲线，左右端高度与切线相同；使用 TextureRect/平铺纹理前检查 Godot 滤波、Wrap 模式，避免缩放导致间隙。
4. 较小物件（消防栓仅 34×70）在世界实际分辨率下必然简化细节；场景使用 Pixel Snap 与适合项目风格的纹理过滤方式，再进行远近观感 QA。
5. 整套为 v01 **候选美术素材**，已完成文件级尺寸、透明度检查，但尚未在真实 Godot 长街完成落位、遮挡与风格统一验收；集成后仍需与建筑/地面/人物共同检查。
