# 《寒潮清单》第一季完整剧情剧本（v1.0）

> 原创主线：**一场死亡、一场重生、七天采购、七天寒潮**。这是可交给开发 Agent 逐事件制作的剧本基线：包括人物、小节、对话、选择、状态效果和结局。所有台词可后期润色，但事件逻辑与 flag 命名应保持一致。

## A. 故事概要与类型

**类型**：轻度复仇/逆袭爽剧 + 极寒生存 + 温暖安全屋日常；不涉及复杂悬疑、僵尸战斗和超自然系统。

**一句话梗概**：极寒末日第五天，被暂住的好友欺骗、失去最后物资的许知夏冻死在自家小楼的楼道。她重生回七天前，没有无限空间，也没有突然到账的一亿现金，只带着上一次的记忆和一张自己写下的采购清单。这一次，她从搬空超市货架开始，将外婆留下的旧两层小楼一步步改造成温暖安全的堡垒。等所有人相信末日真的来了，曾经嘲笑和背叛她的人才第一次敲响那扇加固的门。

**时间**：虚构城市“临江市”，初冬。D-7 至 D-1 为灾前七天；D0 极寒降临；D+1 至 D+7 首轮灾后生存。新闻与电台不引用真实灾难预测。玩家默认单人生活，是否帮助他人由选择决定。

**基调**：快、直白、爽，但不极端猎奇；嘲笑与反转可以明显，避免靠虐待、血腥惩罚和大量无意义“打脸”堆剧情。主动做物资交换和帮助好人，也应能获得满足感。

## B. 角色卡

| 角色/ID | 身份/立场 | 动机 | 表现重点 |
|---|---|---|---|
| **许知夏 `protagonist`** | 24 岁，电商仓储运营；拥有外婆留下的旧两层小楼；玩家主角 | 改写自己死于寒潮的命运 | 理智、肯吃苦，偶尔吐槽；重生后行动坚决；参考画风为正常比例像素人物，不照搬参考图人物 |
| **孟雨薇 `meng`** | 原本借住在旧小楼的好友，灾后趋利避害 | 想借许知夏的准备保障自己 | 灾前轻视，灾后求援；不是无故作恶的疯子，行为要有人性弱点 |
| **陈守诚 `chen`** | 小区维修工，邻居称陈叔 | 尽力维持住宅设备运转 | 老实、会修电路、能用实际技能回报帮助 |
| **唐宁 `tang`** | 街角便利店老板 | 保护小店与病中的母亲 | 有交易信誉，会提供灾后物资交换渠道 |
| **韩启程 `han`** | 自封业主群管理员 | 维护表面秩序，实则害怕失控 | 嘲笑者兼冲突催化剂，后期并不一定变成反派 |
| **天气播报/电台 `radio`** | 城市公共广播 | 公布天气、电网与互助消息 | 承担背景变化、音效和世界观说明 |

### 关系与状态 flag

以布尔/整数保存；默认 false/0。剧情事件与结局仅依赖以下稳定字段，不要动态发明新变量。

```yaml
extra_cash: false             # P01 是否通过卖旧车多拿 12000 元
shared_spare_key: false       # P04 是否把备用钥匙交给孟雨薇
chen_helped: false            # P03 是否帮助陈叔修理设备
tang_helped: false            # P06 是否支援唐宁的小店
meng_helped: false            # D02 是否对孟雨薇提供无偿帮助
meng_exposed: false           # D05 是否在群内公布钥匙/偷窃事实
han_helped: false             # D04 是否给韩启程物资或帮助排险
radio_repaired: false         # D06 是否修复收音机/信号
share_heat: false             # D07 是否愿意开放短时供暖互助
help_count: 0                 # 仅第一次帮助 chen/tang/han 中每人一次计数
comfort_score: 0              # 家具/生活设施累计，供结局判断
ending_id: ""                # CLEAR_WARM / CLEAR_SOLO / CLEAR_BARELY / FAIL_COLD
```

数值代价由 GDD 的库存系统扣除；所有选项都要求有资源/行动点的前置检查。资源不足时选项灰显并说明原因，同时保留**不需要资源的选择**，禁止卡死剧情。

## C. 开场演出 `P00`：前世的最后一夜

**触发**：点击“新游戏”；场景为冰封公寓门外走廊，短横版可行走空间，人物动作缓慢。时长目标 45–75 秒，可跳过二刷。

**画面**：楼道尽头红色应急灯忽明忽暗，窗外风雪，主角只剩最后一点体力。厚重安全门紧闭，房间里传出微弱暖光。

**对白**：

- `旁白`：寒潮降临的第五天。城市停电，供暖中断。零下四十三度。
- `许知夏`：雨薇……开门。我的药和剩下的水还在里面。
- `孟雨薇（门内）`：不是我不想开。你那点东西，根本不够我们撑到明天。
- `许知夏`：备用钥匙，是我亲手交给你的。
- `孟雨薇`：对不起。人总要先顾自己。
- `许知夏（内心）`：如果……能够回到七天前。
- `旁白`：视野被白色吞没。风声骤停。

**转场**：闹钟声——「11 月 15 日 07:00」。主角在温暖的旧房间醒来，手机新闻标题“未来一周有降温趋势”。

- `许知夏`：十一月十五号……我真的回来了？
- `许知夏`：七天。这次，我绝不会再把命交给别人。
- **屏幕中央标题**：《寒潮清单》 / “距寒潮还有 7 天”。

**游戏状态**：D-7；现金 48,000；基础 8 份食物、水 12L；解锁“手机采购清单”；显示三项初始任务“买水、买食物、检查门窗”。

## D. 第一幕：灾前七天

### `P01` D-7《第一张清单》

**触发**：起床后，首次打开采购清单，必须完成一次超市购买并回家入库。教程可跳过提示，不跳过实际交互。

**场景与对白**：

- `许知夏`：饮用水、食物、保温、供电……上一世最缺的东西，这次都要提前准备。
- `手机新闻`：气象部门提醒：强冷空气可能提前抵达。市民暂不必过度囤货。
- `超市店员`：你这是给公司采购？一车都是水和泡面。
- `许知夏`：算是吧。给未来的自己采购。
- `店员`：哈哈，那你可得留点生活费。

**选择（资金支线）**：手机弹出旧车回收报价。

1. `卖掉闲置电动车`：现金 +12,000；`extra_cash=true`；旁白“反正寒潮后也骑不出去了”。
2. `保留电动车`：不增加资金；旁白“那是她工作多年攒下的第一件大件物品”。

**交互**：买至少一箱水和一箱速食食品，结账，配送回家并入库。**完成判定**：购买、支付、物流和入库状态连续正确。

**结尾短句**：`许知夏`：第一批，到了。

### `P02` D-6《有人笑我疯了》

**触发**：次日早晨，在五金店购买或浏览取暖设备后；不要求买得起全部设备。

- `韩启程（业主群消息）`：最近有个住户天天往楼里搬东西。别把消防通道堵了。
- `孟雨薇`：知夏，你最近怎么回事？又买货架又买取暖器，你不会真信网上的末日说吧？
- `许知夏`：信不信都没关系。我买的是安心。
- `孟雨薇`：那你可别到时候来找我借钱。
- `许知夏（内心）`：这次，当然不会。

**任务**：浏览五金店的门窗密封、取暖器、发电机，完成“装修计划”里的任意一项。玩家若只浏览，照常推进；不强制错误购买。

### `P03` D-5《陈叔的工具箱》

**触发**：玩家第一次尝试安装发电机或加固门窗时，陈叔出现。

- `陈叔`：这线路有点老，你要是接大功率取暖设备，最好先检查负载。
- `许知夏`：陈叔，能不能帮我看看？我可以付维修费。
- `陈叔`：钱先不急。我工具箱里有根线老化了，想换掉。
- `许知夏（内心）`：上一世大楼停电时，只有陈叔还在挨家挨户帮忙。

**选择**：

1. `给陈叔一盒维修零件`（需 `scrap_parts>=1`；扣除 1 盒）：`chen_helped=true`, `help_count+1`。陈叔赠送“简易电力检查”提示功能（在建造面板预报夜间供电缺口）。
2. `给陈叔 300 元代买零件`（现金≥300）：同上，扣 300。
3. `暂时不帮`：无扣除，仍可使用基本电力面板，但不显示额外风险提示；不锁剧情。

**任务**：建设或检查至少一项基础设施。

### `P04` D-4《备用钥匙》

**触发**：玩家第二次回家后，孟雨薇在门外。

- `孟雨薇`：你最近锁门锁得这么紧？以前不都把备用钥匙放我那儿吗？
- `许知夏（内心）`：就是这把钥匙，让我死在上一世的楼道。
- `孟雨薇`：怎么突然不说话了？我还能害你不成？

**选择**：

1. `拒绝交钥匙`：`shared_spare_key=false`；`许知夏`：以后各管各的，没事别进我的房间。
2. `交出备用钥匙，暗中观察`：`shared_spare_key=true`；解锁 D+5 更明确的钥匙偷窃事件；这样做是玩家主动选的高风险路线。

**玩法**：批发仓解锁；手机新闻第一次出现异常寒流路线图。任务是至少再采购一类物资。

### `P05` D-3《价格开始变了》

**触发**：早晨打开商品清单；超市食物/水涨价，五金燃料/供暖设备涨价。

- `超市广播`：因物流延误，部分商品暂停促销，每人限购。
- `顾客甲`：昨天还这么便宜，怎么突然涨价？
- `许知夏（内心）`：来了。和上一世一模一样。
- `韩启程（群消息）`：大家不要恐慌，个别住户囤货是对他人不负责。
- `许知夏`：今天要做的不是争论，是把漏掉的东西买齐。

**任务**：打开“清单缺口”面板（显示未来预计 7 天所需食物、水、燃油与保温）；不要求全部满足才能过夜。系统应给实际数值提示。

### `P06` D-2《便利店的请求》

**触发**：街角唐宁便利店临时事件。

- `唐宁`：我妈在楼上病着。医药配送说要晚三天，店里东西也快卖空了。
- `许知夏`：仓库里还有一批常用药和水。我可以先匀你一点。
- `唐宁`：如果寒潮真来了，我还能用店里的仓库和你换货。

**选择**：

1. `支援 1 个急救包`（需 `medkit>=1`）：扣 1，`tang_helped=true`，`help_count+1`。灾后交易点优惠、优先开放。
2. `支援 1000 元采购款`（现金≥1000）：扣 1000，效果同上。
3. `自己也要留退路`：唐宁理解，无惩罚，灾后正常价交易点仍开放。

**结尾**：`唐宁`：你这清单写得这么细，等风雪过去，借我抄一份。

### `P07` D-1《最后一次出门》

**触发**：灾前最后一天；空气微冷，店铺提前打烊，货架售罄表现。

- `手机紧急提示`：寒潮预警提升为红色；夜间温度预计异常下降。
- `孟雨薇`：你真打算一个人窝在这里？我都订好去外地的车票了。
- `许知夏`：祝你一路顺风。
- `孟雨薇`：等证明你是杞人忧天，我再来看你囤的泡面。
- `许知夏（内心）`：不必了。等明天，你会明白的。

**三选一的最后行动提示**（只消耗行动点，不强制其中一个选项）：

1. `再去补一次物资`：打开已限购的商店。
2. `检查门窗与发电设备`：打开建造/检查界面。
3. `准备一顿热饭`：若有厨房则舒适度+1；否则播放普通晚餐短场景。

**结束当日演出**：屋外第一片雪落下，主角锁上加固门；全黑一秒，巨大的风声响起。字幕：**“寒潮正式降临。”**

## E. 第二幕：极寒降临

### `D00` D0《外面零下二十度》

**触发**：过渡演出后，自动天气与生存结算。

- `电台`：异常强降雪席卷临江市，多条交通线路停运，请市民尽量留在室内。
- `许知夏`：这不是普通降温。这只是开始。
- `韩启程（群消息）`：谁知道附近哪儿还有取暖器？有人发个链接。
- `许知夏（内心）`：昨天还说我囤货浪费，今天就在求购买链接了。

**玩法**：室外雪层开始堆积；室内温度面板首次成为显著 HUD，玩家可用 1 AP 紧急补装/维修；引导检验供暖。

**若供暖充足**：`许知夏`：暖风正常，水和粮都够。今晚先睡个好觉。

**若供暖不足**：`许知夏`：温度掉得太快了……还得想办法补救。

### `D01` D+1《全城停电》

**触发**：每天开始播放电网故障，市电永久关闭。

- `电台`：部分城区已出现大范围断电，抢修时间暂时无法确定。
- `许知夏`：终于到了。备用电源，启动。
- `发电机音效`：（若可运转）低沉转动声，屋内灯逐盏亮起。
- `孟雨薇（消息）`：知夏，你那里还有电吗？我手机快没电了。
- `许知夏（内心）`：上一世，我也是这样求助的。

**分支**：供电充足则暖灯闪亮 + 稳定供暖提示；不足则设备熄灭 + 风雪音上升，玩家可在本日用 AP 修复或补充燃料。该分支只改变即时表现和资源，不改变主线对白结构。

### `D02` D+2《她站在门外》

**触发**：前世好友孟雨薇第一次正式登门；镜头采用室内/门外冷暖对切。

- `孟雨薇（敲门）`：知夏！借我点水，还有吃的，我那边什么都没有了。
- `许知夏`：你不是说我囤货是浪费吗？
- `孟雨薇`：我那时候又不知道会这样……我们不是朋友吗？
- `许知夏（内心）`：上一世，她也是这么说的。

**选项**：

1. `隔门交易`（玩家食物≥4）：她用一盒药换你 4 份食物，资源 -4 食物、+1 急救包；`meng_helped=false`，与原始背叛保持距离。
2. `给她一份应急物资`（玩家食物≥2 且水≥2L）：资源 -2 食物、-2L 水，`meng_helped=true`；只说明“不会再给你钥匙”。
3. `关门`：零资源消耗；`许知夏`：每个人都要为自己的决定负责。

**注意**：没有任何选项直接把玩家赶出安全屋；纯拒绝也能继续剧情。

### `D03` D+3《发电机卡住了》

**触发**：电力事件第一次强制“故障演习”；不是随机永久摧毁重要设备。

- `许知夏`：怎么偏偏这个时候异响？
- `陈叔（门外）`：我听到机器的动静了，是不是皮带松了？
- `许知夏`：陈叔，您还好？
- `陈叔`：凑合。我还能帮你把这东西修好。

**条件结果**：

- `chen_helped=true`：陈叔免费协助修好，发电机不消耗配件；`陈叔`：你帮我换过线，这回算我还你。
- 否则若 `scrap_parts>=1`：玩家消耗 1 零件盒自行修好；`许知夏`：还好备用零件提前买了。
- 否则：停机 1 天，在下一日可消耗 AP 修复；当日温度结算必须反映能源损失；不因剧情永久损坏设备。

### `D04` D+4《从窗外传来的声音》

**触发**：业主群管理员韩启程在门外或楼下广播求助。

- `韩启程`：楼道入口被雪堵住了，老人那边快出不来！
- `许知夏`：你不是说大家都不要恐慌吗？
- `韩启程`：我错了。现在先别说这个，能不能帮忙？

**选项**：

1. `借出工具并帮忙清路`（本日 AP≥1 或已经有工具任务完成）：消耗 1 AP；`han_helped=true`, `help_count+1`；获得 1 维修零件盒作为邻居感谢。
2. `给一份应急物资`（食品≥2、水≥2L）：消耗食物2、水2；`han_helped=true`, `help_count+1`；韩启程后续成为可靠广播中转人。
3. `只通过门口指点`：不消耗资源；韩启程仍能找到办法，`han_helped=false`，不强制坏结局。

**场景**：风雪在楼梯上堆积；已升级的安全屋灯光更暖，强化反差。

### `D05` D+5《第二把钥匙》

**触发**：上一世的背叛节点，依据 `shared_spare_key` 分支。

**若交出备用钥匙**：

- `音效`：门锁轻轻响动。
- `许知夏`：雨薇？你怎么有钥匙进来？
- `孟雨薇`：我只是想借点燃油。我那里真的撑不住了。
- `许知夏`：借东西，至少先问一句。
- `孟雨薇`：你明明有这么多，为什么连一点都不肯分？

**玩家选择**：

1. `收回钥匙并公开事实`：`shared_spare_key=false`、`meng_exposed=true`；若存在燃油，物资不扣；群消息展示邻居提醒保管钥匙。
2. `收回钥匙，但私下解决`：`shared_spare_key=false`；若燃油≥1，可以自愿交易（扣 1 燃油、获得 1 维修零件盒），否则无消耗。

**若未交备用钥匙**：

- `孟雨薇（门外）`：我知道你还在里面。能不能再谈谈？
- `许知夏`：我们可以交易，但门不会再为你随便打开。
- `孟雨薇`：……原来你真的不一样了。

**本事件不必让 NPC 无条件盗走资源**；以前的错误能通过玩家前期决定规避，体现“改写命运”。

### `D06` D+6《零下四十度预警》

**触发**：第二轮寒潮强预警，抗寒阈值升至 25。

- `电台（断续）`：……今日夜间，最低温可能突破零下四十度……请保持通风与供暖安全……
- `许知夏`：比上一世还冷。这是最后的考验。
- `唐宁（消息）`：我这里还有电台零件，想换一份燃油或修理材料。我们可以互相通个消息。

**任务/选择**：

1. `修复收音机与屋顶天线`（需维修零件≥1 或现金/交换资源的合理替代）：消耗 1 维修零件盒；`radio_repaired=true`；解锁 D+7 高信息完整结局文案。
2. `优先加固住房`：打开建造，保留原资源，`radio_repaired=false`。
3. `只靠已有储备`：直接进入晚间准备。

**夜晚**：高强度风雪、窗户结霜、暖黄灯光在大雪中更突出；不足时明确提示如何挽救。

### `D07` D+7《窗内的灯》

**触发**：D+7 晚上资源结算后主角仍活着。剧情要求：玩家主动决定是否开放有限互助，之后按条件进入结局。

- `广播`：风暴中心已向北移动，第一轮极端寒潮预计明早缓和。
- `许知夏`：七天……我真的熬过来了。
- `镜头`：楼外被雪覆盖的城市；窗内安全屋灯光温暖，货架被物资填满。
- `陈叔（若曾帮助）`：灯亮着，我就知道你这里没事。
- `唐宁（若曾帮助）`：街上还有人活着。看来准备并没有白费。

**最终选择**：

1. `开放一小段时间的暖屋互助`：若拥有食物≥4、水≥4L、实际抗寒≥25，消耗食物4、水4，`share_heat=true`；展示邻居在门口排队短暂取暖的温暖场景。
2. `继续关闭大门，先守住自己`：`share_heat=false`；展示主角吃上热饭，关上窗帘，坐在窗边休息。
3. `向电台发送安全讯息`：若 `radio_repaired=true`，广播传出安全屋位置，为后续故事埋伏笔；可与前两项兼容，不作为终结分支的互斥选项。

**结局逻辑**：

- 若任何一天晚结算生命≤0：`FAIL_COLD`。
- 若 D+7 存活且 `help_count>=2 && share_heat && radio_repaired`：`CLEAR_WARM`。
- 若 D+7 存活且 `comfort_score>=5 && 食物>=8 && 水>=12`，但未满足温暖结局：`CLEAR_SOLO`。
- 其他存活：`CLEAR_BARELY`。

> 结局条件要在游戏开发时可视化与测试。基于上述门槛，资源不足时不能显示不可选择的互助按钮为可执行。

## F. 四个结局的完整短场景

### `CLEAR_WARM`《窗内有一盏灯》——温暖结局

**画面**：安全屋剖面，地下仓库与发电机工作，上层一张桌旁放着热茶。几位邻居在门厅取暖，门外仍是风雪。

- `唐宁`：我以前总觉得，末日里所有人都会只顾自己。
- `陈叔`：有地方能一起坐下来喝口热水，就已经很好了。
- `许知夏`：我囤物资，是为了活下去。现在看来，也能让更多人活下去。
- `广播`：临江市东区发现仍在工作的民间避难点……
- `旁白`：这一世，她没有把钥匙交出去，却为值得信任的人留了一盏灯。

**通关卡文案**：`寒潮第七天：灯火尚存。` 统计房间数量、库存、帮助人数和生命值。

### `CLEAR_SOLO`《一个人的豪华堡垒》——爽剧结局

**画面**：窗外雪暴，窗内暖炉、热食、整墙储物架和舒适卧室；玩家可以在通关后继续自由查看自己的房间。

- `韩启程（群消息）`：有人那里还有热水吗？
- `许知夏（关上消息）`：这次，我终于不用再求人了。
- `许知夏`：明天要做什么呢？先把厨房再升级一下吧。
- `旁白`：全城的寒夜没有结束，但她已经拥有属于自己的温暖。

**通关卡文案**：`寒潮第七天：我把日子过成了从前不敢想的样子。`

### `CLEAR_BARELY`《撑过今晚》——普通结局

**画面**：房间里还有些杂乱，温度表勉强达标，最后一点燃油在燃烧。主角疲惫地笑了。

- `许知夏`：我没有准备得那么完美……但至少，这次没倒在门外。
- `广播`：未来几日气温仍将偏低，请勿放弃自救。
- `许知夏`：还有时间。明天继续把这里修好。

**通关卡文案**：`寒潮第七天：活下来，就是新的开始。`

### `FAIL_COLD`《没有准备好的夜晚》——失败分支

**触发**：任一天生命≤0；画面暂停，显示当晚失败原因与补救建议，不重演复杂死亡镜头。

- `旁白`：夜里，暖气停了。窗缝的风一点点吹散房间最后的热度。
- `许知夏`：还差一点……
- `系统说明`：本次失败原因：供暖缺口/缺水/缺粮（选择主要原因）；可以读取前一日自动存档，修正清单。

**按钮**：`重试前一天`、`读取手动存档`、`返回标题`。不可强迫从 D-7 开始，也不触发新一轮“世界重生”的主线。

## G. 可选支线事件（首季建议至少完成前 3 个）

### `S01`《货架最后一包泡面》— 灾前 D-3 至 D-1

超市一个小孩盯着最后的泡面。玩家可自己购买，或让出商品（立刻获得唐宁/陈叔类 NPC 好感插画和少量舒适分，不增加重大主线 flag）。**目的**：展示提前囤货的社会反差，不加入惩罚。

### `S02`《窗边的一盆绿植》— 建造舒适度事件

玩家首次摆放盆栽/台灯/餐桌，许知夏自言自语：“末日不代表房间必须像仓库。”增加 `comfort_score+1`（每种装饰首次摆放计分，防止重复刷分）。

### `S03`《一顿热火锅》— D0 至 D+7 任一天

若安全屋有电/火源、水≥2L、食物≥4份，玩家可花掉食物4、水2L播放短动画：外面暴雪，屋里锅冒热气，舒适 +2（每存档最多一次）。适合宣传短视频素材。

### `S04`《屋顶的小狗》— D+2 至 D+5

听见轻微犬吠。玩家可给 2 份食物让小狗暂时留在门厅，也可通过邻居寻找主人；这是美术/配音扩展候选，首个版本不必实现宠物寻路系统。

### `S05`《物资交换》— D+3 以后

唐宁带来少量维修零件，玩家用额外食物/水/药交换。交易量与条件透明显示；`tang_helped` 可获得更优惠的交换率，但不应让其他玩家无法通关。

### `S06`《没有发出去的消息》— D+6

主角手机收到上一世留在草稿箱的短信：“下雪前记得多买点水。”主角删掉草稿，换成“窗内灯还亮着”。**目的**：给短剧式结尾一点情绪收束，不能替代实际生存游戏。

## H. 演出、UI 与文本长度约束

1. 开场 P00 60 秒内优先可理解，玩家二刷可以跳过。
2. 常规每日关键剧情 20–50 秒；玩家第一次看完大概懂因果，第二次可快进/跳过已读内容。
3. **场景交替**：至少让角色在超市拿货、回家搬运、在窗边看雪、与门外 NPC 对话，这些必须以可视动作呈现；不允许全部采用旁白黑底。
4. 对话框显示角色名、头像或小立绘、正文；选项带资源成本与结果预告；决策后即时播一句反馈和物品变化。
5. 日志系统可回看当天及历史对话，避免因为不小心点过就错过剧情；重要情报同步记录进手机“前世记忆”。
6. 结局统计卡显示 `存活天数、物资剩余、最冷夜抗寒差值、房间/设施、帮助次数`，可制作可分享截图，但默认不上传任何玩家数据。
