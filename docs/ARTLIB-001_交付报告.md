## 3. 离线预览页

`素材库/美术总览.html` 由 `tools/build_artlib.py` 生成，**双击即可**：

## 5. 素材台账字段与示例

`素材库/素材台账.csv` 共 **21 列**：

| 必需字段（任务要求） | 本库附加字段 |
|---|---|
| 素材ID、名称、所属分类、对应角色或场景、当前版本、来源、用途、制作状态、审核状态、版权或授权备注、原始文件路径、对应运行时资源路径、制作与修改说明 | 库内文件路径、相关文件、动画帧数、帧率FPS、尺寸、方向、预览文件、精灵图文件 |

**状态区分**：`审核状态` 使用 6 段生命周期 —— `概念草案 / 待审核 / 已通过设定审核 / 正式素材制作中 / 运行时可用 / 已弃用`；
`制作状态` 是产线进度 —— `未开始 / 概念绘制 / 像素精修 / 引擎试用 / 已交付 / 不适用`。
只有 `审核状态 = 运行时可用` 且填了运行时路径才允许进游戏；**「已通过设定审核」不等于可运行**（预览页会显示警告）。

示例记录（节选）：

审核状态    : 待审核
