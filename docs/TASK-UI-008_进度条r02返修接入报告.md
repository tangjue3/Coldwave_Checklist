## 二、接入方式

`TextureProgressBar` 换成「轨道 `TextureRect` + 填充 `NinePatchRect`」：

- 轨道：`TextureRect`，78×12，保持原位置 `(798, y+2)`，**贴图不再被缩放**。
- 填充：`NinePatchRect`，锚在轨道内 `(2,2)`，高 8，宽 `round(74 × ratio)`；
  `patch_margin_left/right = 4`、`top/bottom = 3`，只拉中间、两端圆角保留。
- `ratio = 0` 时 `visible = false`（否则九宫格端帽会残留一个小点）。
- 宽度 < 8px（即 <11%）时夹到 8px，退化成一个小圆点——这是交付说明允许的行为。
- 百分比由 `scripts/dev/hud_preview.gd` 的 `_apply_bars()` 驱动，两套测试数据各带一组百分比。
