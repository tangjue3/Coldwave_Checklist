## 三、预览场景

`scenes/dev/inventory_preview.tscn` + `scripts/dev/inventory_preview.gd`，路由 `--dev-scene=invprev`。

- `World(Node2D：背景 + Camera2D)` 与 `Overlay(CanvasLayer layer=20) → Root(Control 960×540)` 分离，
  UI 全部屏幕空间，不用世界坐标画字。
- 面板用 `Panel + StyleBoxTexture`，九宫格边距**逐项取自 `manifest.json`**：
  主窗 29/39/29/25、详情 25/34/25/24、分类 22/20/22/20、弹窗 24/35/24/21、
  Tooltip 24/28/24/20、按钮 24/16/24/16、分类按钮 24/15/24/15。
- 除详情栏外全部 **1:1 原生尺寸**：主窗 760×430 @ (100,56)、分类 138×302、格位 58×58 六列五行
  （步长 63）、Tooltip 256×156、弹窗 350×248。
  **详情栏 194→180**：760 宽的主窗按原生宽度摆不下 138+373+194，按九宫格横向收 14px，
  高度与四角保持不变；这是全场景唯一一处非 1:1。
- 字体沿用 TASK-UI-006 定稿集 `assets/ui/labelsettings/final/`：标题 / 正文 / 数值宋体，
  物品描述与 Tooltip 描述用霞鹜文楷（"人写的东西"）。**79 个 Label 全部有 `LabelSettings`，
  贴图里没有一个字。**
- 物品图标优先复用已批准的 `assets/ui/hud/v01/HUD_icon_*`（面包 / 水 / 木材 / 布料 /
  手电筒 / 钳子 / 钥匙），**没有复制、没有重新领号**。

## 四、测试数据隔离

`ITEMS` 是脚本里的 9 条 **fixture**，`负重 28.4 / 40.0 kg` 由 `Σ(数量 × 单位重量)` 算出，
不是写死的贴图文字；进度条复用 TASK-UI-008 的 78×12 轨道 + 74×8 九宫格填充。

屏幕右下角常驻 **「测试数据：数量与属性均为示意，未接入背包玩法」**，左下角
「物品整理与交互预览 · 测试数据 / 非真实库存」。分类切换、点格子、悬停 Tooltip、
数量加减、关闭窗口都是**纯 UI 演示**，不读写 `GameState`，不调用 `SaveManager`，
也不假装购物 / 仓储 / 生存系统已实现。

## 六、与交付包 `05-预览/HUD…合成示例` 的差异

对照图：`tests/screenshots/ui010_compare_ref.png`（上为交付包合成，下为 Godot 实机）。

**刻意差异（不是缺陷）**

1. **全部文字改为原生 Control 绘制**，交付包合成图里的文字是位图。这是任务硬要求。
2. **尺寸按原生 1:1**：格位 58×58、间距 5、分类底板 138×302；合成图为在 760 宽里塞下更多内容，
   把格位、分类、详情都等比缩小了（约 0.9×）。实机格位更大、留白更多、小字更可读。
3. **负重条用已批准的 78×12 r02 轨道**，合成图里是约 110 宽的自定义条；本轮不缩放旧图。
4. **物品只有 9 件**，且右下角多一个禁用锁格（用于演示第五态）；合成图有 12 件、无禁用格。
5. **多了「测试数据」双角标**；合成图只有一行小字说明。
6. **详情栏的"重量"是整组总重（0.9 kg = 3 × 0.3）**，合成图写的是单件 0.3 kg。
7. 描述用霞鹜文楷并允许换行，合成图是单行宋体。

**缺口（需要美术总监裁定）**

1. **物品图标集不够**：合成图里的现金、水袋、碗、绳结等图标，本包没给，
   当前用 HUD 已有图标代位（手电筒 / 钳子 / 钥匙等）。要完全还原需补一批物品图标，
   或明确"首批预览允许代位"。
2. **12 枚新功能图标只上屏了 4 枚**（背包、网格、医疗、锁定）；搜索、整理、转移、
   筛选、信息、使用、关闭、删除等尚未在界面里出现，需等对应功能页开发。
3. **详情栏被九宫格收窄 14px** 才放下 6 列格阵。若希望全部 1:1，需要美术给一张
   ≤180 宽的详情栏，或允许把主窗加宽 / 格位改小。
4. **Tooltip 只显示描述第一句**：面板固定 156 高，放不下完整长句；完整描述留在右侧详情栏。
5. `05-预览/` 与 `06-参考资料/` 里的概念图**没有**当运行时贴图使用。

## 七、过程中修正的五个问题

1. 详情栏 / 弹窗 / Tooltip 的标题最初压在冰霜描边上 → 按各图 `texture_margin_top`
   （34 / 35 / 28）重排内区起点。
2. 加减号按钮缩到 32×32 后塌成"D 形" → 根因是源图左侧 10px 全透明，九宫格左帽落在透明区。
   给四个小按钮样式加 `region_rect = Rect2(10,3,130,33)` 裁掉透明边，边距改 8/6/8/6。
3. 脚本直接选中格子时没清旧选中，出现两个琥珀框 → `_select()` 先清全部再置位。
4. 五态样张里「拖拽」误用了选中态贴图 → 改用真正的 `INV_slot_drag_58x58`。
5. `--inv-state=selected` 与默认态截图相同 → 改为选第 4 格（布料）。
