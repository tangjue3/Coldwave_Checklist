# 工程复现说明（换电脑 / 新人接手）

本仓库**不提交引擎二进制**（编辑器约 180MB，导出模板约 1.2GB）。`.tools/`、`.godot/`、`builds/web/` 全部在 `.gitignore` 里，克隆后按下述步骤补齐即可。

---

## 1. 指定版本

| 项 | 值 |
|---|---|
| 引擎 | **Godot 4.7.2 stable** |
| 完整版本串 | `4.7.2.stable.official.ed1daf0bf` |
| 脚本语言 | GDScript（**不要**下载 Mono / .NET 版） |
| 渲染后端 | GL Compatibility |
| 工程配置 | `config/features = PackedStringArray("4.7", "GL Compatibility")` |

> 用 4.6 或 4.8 打开并保存会静默改写 `project.godot`。版本不符时请先核对，不要直接覆盖提交。

## 2. 官方下载来源

- 下载页：https://godotengine.org/download/windows/
- 本版本发布页：https://github.com/godotengine/godot/releases/tag/4.7.2-stable
- Windows 编辑器：`Godot_v4.7.2-stable_win64.exe.zip`（**86,013,866 字节**，约 82 MiB）
- 导出模板：`Godot_v4.7.2-stable_export_templates.tpz`（**1,281,349,702 字节**，约 1.19 GiB）
- macOS / Linux 用同一发布页上对应平台的编辑器包；模板包跨平台通用。

**官方 SHA-256**（GitHub Release 资产的 `digest`）：

```
Godot_v4.7.2-stable_win64.exe.zip      sha256:731980f9608d61333e5baf54a2ef17210acc7a538446c0cb9969f002aca1e953
Godot_v4.7.2-stable_export_templates.tpz sha256:f298490b8d44d934be425a5a65a51bf15f422428b229a06a6e11d9ffea248011
```

## 3. 版本校验方式

下载后先校验文件，再校验引擎自报版本：

```bash
# Windows (PowerShell)
Get-FileHash .\Godot_v4.7.2-stable_win64.exe.zip -Algorithm SHA256

# 或 Git Bash / macOS / Linux
sha256sum Godot_v4.7.2-stable_win64.exe.zip
```

解压后：

```bash
Godot_v4.7.2-stable_win64_console.exe --version
# 期望输出：4.7.2.stable.official.ed1daf0bf
```

编辑器内也可通过 `Help > About Godot` 查看。工程里的 `scripts/dev/startup_smoke.gd` 会检查 `Engine.get_version_info()` 是否为 4.7，版本不符会打印 `[SMOKE][FAIL]`。

## 4. 新电脑打开项目的步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/tangjue3/Coldwave_Checklist.git
   cd Coldwave_Checklist
   ```
2. **放引擎**：把解压出的两个 exe 放到工程根目录的 `.tools/godot/`（该目录已忽略），或者装到系统任意位置、把命令换成实际路径。
   > 本仓库 README 里的命令默认使用 `.tools/godot/Godot_v4.7.2-stable_win64_console.exe`。
3. **打开工程**：启动 Godot → `Import` → 选择工程根目录的 `project.godot`。首次打开会自动重建 `.godot/` 导入缓存（字体、图标、参考图），不需要手动拷贝。
4. **跑一遍自检**
   ```bash
   .tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path . --import
   .tools/godot/Godot_v4.7.2-stable_win64_console.exe --path . -- --shot=smoke.png --quit
   ```
   期望 `通过 24 项，失败 0 项`，截图落在 `tests/screenshots/`。
5. **需要 Web 导出时才装模板**（见第 5 节）。只做桌面运行可跳过。

## 5. 导出模板与 Web 导出

### 完整安装（推荐）

Godot 编辑器：`Editor > Manage Export Templates > Install from File`，选择下载好的 `Godot_v4.7.2-stable_export_templates.tpz`。
等价于把包内 `templates/` 内容解压到：

| 系统 | 路径 |
|---|---|
| Windows | `%APPDATA%\Godot\export_templates\4.7.2.stable\` |
| macOS | `~/Library/Application Support/Godot/export_templates/4.7.2.stable/` |
| Linux | `~/.local/share/godot/export_templates/4.7.2.stable/` |

目录内应有 `version.txt`（内容 `4.7.2.stable`）与各平台模板文件。

### 只做 Web 冒烟测试（可选省流量方案）

1.2GB 全量模板里 Web 部分只有约 50MB。仓库提供 `tools/fetch_web_templates.py`：通过 GitHub API 的 HTTP Range 只下载 `web_*.zip` 与 `version.txt`，输出到临时目录，再按上面的路径放置。

```bash
python tools/fetch_web_templates.py D:/tmp_web_tpl
cp -r D:/tmp_web_tpl/4.7.2.stable/* "$APPDATA/Godot/export_templates/4.7.2.stable/"
```

脚本需要 `gh auth token` 与本地代理 `127.0.0.1:7897`；网络环境不同时直接下全量包更省事。

### 导出并本地验证

`export_presets.cfg` 已随仓库提交（Web / 默认单线程 / Compatibility）：

```bash
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release "Web" builds/web/index.html
python tools/serve_web.py                      # http://127.0.0.1:8060
# 另开终端：启动带 --remote-debugging-port=9333 的无头 Chrome
node tools/web_smoke_cdp.mjs                  # 等待引擎就绪、模拟按键、截三种视口
```

`tools/serve_web.py` 会补上 `.wasm` 的 `application/wasm` MIME 类型；用普通静态服务器时也要确认这一点，否则 `WebAssembly.instantiateStreaming` 会失败。

## 6. 哪些东西不需要提交

| 路径 | 原因 |
|---|---|
| `.tools/godot/*.exe` | 引擎二进制，180MB，按第 2 节重新下载 |
| `.godot/` | 导入缓存，首次打开自动重建 |
| `builds/web/` | 导出产物，随时可重新生成 |
| `*.zip` / `*.tpz` | 交接包原始压缩件与模板包 |
| `*.import` / `*.uid` | **这些要提交**（记录导入参数与资源 UID） |
| `export_presets.cfg` | **要提交**（保证 Web 导出可复现，且不含本机绝对路径） |
