## 2. 人物与购物车分割（本轮最重要的一项）

视频里的购物车是**灰紫色金属线框车**，与工程正式资源 `ART_FURN_103 r03` 不是同一资产。
人物双手握住车把圆形端盖，两者在像素上连成**单一连通域**（面积 106414），不能靠连通域分离。

`tools/video/segment_002.py` 的做法：

1. 逐帧检测「亮桃色手 → 深灰圆形端盖」的接触点（96 帧 x 481–636，随漂移变化）；
2. 手部带内按颜色分离：桃色手 R−B≈60（205/171/143），端盖/横杆 R−B≈20–30；
   **只保留暖色皮肤 + 1 px 描边邻域**，保留绕过端盖的弯曲手指；
3. 其余区域用接触点切线 + 连通域取人物，车体（端盖、横杆、竖杆、篮网、车轮）全部剔除；
4. 对人物做 G−max(R,B) 色度键抠像 + despill + 颜色外扩。

**结果（可复核）**

- 96 张纯人物抠像帧，**车体残留 0 px**（手部带以外统计）；
- 人物 bbox 高 600–612 px，全身（头/发/躯干/挎包/双腿/双靴/手）完整，无断腿；
- 手呈自然**握把杯状**（上翘拇指 + 掌心），不是平切的手臂；
- 成品帧绿色残留 **0 px**；
- 对照证据：`转存库/VIDEO-INTEGRATE-002/compare_person_cart_split.png`。

游戏里的购物车**继续完全由 `ART_FURN_103 r03` 四件分层渲染**（r03-back / r03-front /
r03-cargo-half / r03-cargo-full，实测路径与 `PushableCart` 代码一致），
图层顺序 Back(z0) → Cargo(z0) → Player → Front(z1) 未改，**没有出现第二辆车**。
未使用低车把 r01。

### 2.1 一个必须说明的资产比例差与工程对齐

视频购物车把在人物身高 **65%** 处，而 `r03` 加高把在 **56%** 处，
直接套用会让**手悬空约 15 世界 px**（手心到车把端盖实测 Δ=(13.8, 15.2) 世界 px）。
任务明确要求手不能悬空，因此 `tools/video/integrate_002.py` 增加了
`align_hand_to_handle()`：**连续位移场**把前臂平滑下压（dx=8, dy=58 贴图 px），
肩部 smoothstep 过渡、躯干/头/腿/脚零改动。

- 不缩放、不插值、不重绘、不新增像素，**人物形象 / 服装 / 发型 / 脸型 / 配饰完全不变**；
- 建模为「姿态对齐」而非美术重绘，可在脚本里一键关掉回退；
- 曾试验过的两种方案（刚体旋转、挖空贴回）分别产生**重影手臂**和**肩部缺口**，
  已判定不可采用，没有用错误结果冒充完成；
- 实机验证：四张真实 Godot 截图（待机 / 推行 / 满载 / 停止）手均贴住握把端盖，见
  `compare_hand_contact_godot.png`。

> 这是两个独立资产的比例差带来的工程妥协，**请美术审核时重点看手臂角度是否自然**。

## 4. Godot 接入

`PlayerController` 新增三段常量与 `push_anim_available()`；
`push_pose` / `push_walk_active` / `state` 三个既有状态驱动动画切换：

```
普通行走 r10 → 接近购物车 → bind() → push_idle_right
→ push_walk_right(80px/s) → 停止 → push_walk_to_idle / push_idle_right
```

  `player.tscn` 几何、`stretch/mode=canvas_items`、全局渲染配置；

## 6. 尚未解决的问题（如实记录，不标为已修复）

1. **脚底滑动**：源视频是原地跟拍（整组右移 109 px 已补偿，但人物没有真实横向位移），
   游戏按 80 px/s 平移时支撑脚无法锁地。24 FPS 全帧播放已是最优采样，
   降采样只会更差。根治需要带真实横向位移的新视频。
2. **停止过渡相位覆盖 21.9%**：视频只提供一次减速过程，
   7/32 相位能自然衔接，其余直接站稳，没有硬拼。
3. **资产比例差与手臂对齐**：视频车把（65% 身高）比正式 r03 车把（56%）高，
   已用连续位移场把手臂下压贴合；**手臂角度是否自然需美术裁定**。
   若判定不自然，需用户重新生成「推与 r03 同高车把」的视频，或授权微调正式车把资源。
4. **朝左仅 flip_h 镜像**，无独立左向推车帧；本轮只按要求验证右向。
5. **单帧扶车待机**：源视频后段完全冻结，没有呼吸循环。
6. **风格差异**：人物为平滑赛璐璐渲染，货架/购物车为像素素材，两者风格仍不完全统一。
7. **1× 视口物理上限**：960×540 下角色约 162 物理像素高，面容细节有限；
   512×704 贴图在 2× 窗口下才有明显细节优势。
8. **体积与显存**：新增 50 张 512×704 帧，`assets/characters/` 16 MB，
   Web PCK 由 20.90 MB 增至 31 MB；常驻显存按 50×512×704×4 ≈ **72 MB**（未计压缩）。
   若目标平台吃紧需另行裁定。
