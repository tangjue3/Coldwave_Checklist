## 二、预览场景

`scenes/dev/hud_preview.tscn`（`--dev-scene=hudprev`）

- 结构：`HudPreview → World(Node2D: Bg + Camera2D)` + `Hud(CanvasLayer) → Root(Control 960×540)`。
  **HUD 全部在 CanvasLayer 里，没有一个字画在世界坐标。**
- 模块：地点 / 时间 / 天气 三条顶栏、今日清单、生存状态、六格快捷栏、交互提示、资源条。
- 文字：全部 `Label` + `labelsettings/final/*`。标题 18 宋 SemiBold、正文与数值 宋 Regular 14、
  任务正文霞鹜文楷 14、序号与长数值 11–12。
- 数值列固定宽度右对齐，位数变化不推走进度条。
- 快捷栏：1–6 数字键与左右方向键切换选中格，选中态换 `HUD_slot_selected` 贴图（不是代码画框）。
- 测试数据通过 `--values=b` 整体换一套（位数不同），并打 `DEV · 测试数据` 角标声明未接玩法。
