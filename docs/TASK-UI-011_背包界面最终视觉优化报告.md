先量了 `INV_panel_details_194x310.png` 的亮度剖面，发现中部在 **y≈43–51 有一条装饰霜纹横带**，
上一版把标题放在 y=38，正好被这条亮线穿过。按纹理重排内区：

| 元素 | 改前 | 改后 |
|---|---|---|
| 标题 | 38–64（压在装饰带上） | **56–82**（在装饰带下方） |
| 分隔线 1 / 2 / 3 | 68 / 122 / 174 | **86 / 138 / 190** |
| 图标 + 名称 + 分类 | 76–116 | **92–132** |
| 数量 / 重量 | 128 / 150 | **144 / 164**（两行各 20px，中间不留挤） |
| 描述 | 180–262（82px，长文 3 行会压到按钮） | **196–240（44px）** |
| 使用 / 丢弃 | 22 / 92，62×34 | **26 / 96，58×34，y=254–288**，两键间距 12px |

- 内区左右统一收进 26..154（面板九宫格左右各 25px 边距），不再贴边。
- **详情描述只显示第一句，完整描述交给 Tooltip**（见下节）。描述下缘 240 → 按钮上缘 254，
  **间距 14px**，不再与按钮争空间；按钮下缘 288 距面板底 22px，完整落在九宫格下帽之上。
- 详情按钮原先在 58×34 下被压成扁椭圆（源图左侧 10px 全透明，左帽落在透明区），
  新增 `SBT_dbtn_*` 四态样式：`region_rect = Rect2(10,3,130,33)` + 边距 14/8/14/8，
  与弹窗小按钮同一套修法，现在都是完整圆角矩形。
- 数量角标从 `(28,32,28,20)` 移到 `(32,36,24,18)`，避开占位标记与图标右下角。

## 二、Tooltip：完整描述 / 自动换行 / 动态高度

`_show_tooltip()` 现在：

1. 写入**完整** `desc`（不再裁第一句），`autowrap_mode = AUTOWRAP_WORD_SMART`，固定宽 208px；
2. 用 `Font.get_multiline_string_size(full, LEFT, 208, font_size).y` 算实际换行高度，
   与 Label 的自动换行用同一套字体参数，不靠目测；
3. `desc_h = max(text_h + 3, 20)`，描述起点 y=113，
   `面板高 = clamp(113 + desc_h + 23, 156, 524)`；宽度固定 256，
   **纵向靠九宫格拉伸，四角与冰霜描边不变形**；
4. 位置四边夹紧：`x ∈ [8, 696]`、`y ∈ [8, 540 - 高 - 8]`。

实测：

| 情况 | 面板高 | 位置 |
|---|---|---|
| 单句描述（钳子） | **156**（原生，不虚胖） | — |
| 两句描述（水瓶） | **173** | (401,112)–(657,285) |
| 底行格子 + 长描述 | 173 | 被顶回 **y=356..532**，不出屏 |
| 最右列格子 + 长描述 | 173 | 被夹回 **x=653..909**，不出屏 |

Tooltip 内区也下移了：装饰横带在 y≈29–33，标题/分类/分隔/数量改到 40 / 64 / 86 / 92，
描述从 113 起，不再被亮线穿过。

## 三、图标映射审计与明确占位图

做了 9 件物品的图标对照表逐张核对：

| 物品 | 图标 | 结论 |
|---|---|---|
| 面包 / 水瓶 / 木材 / 布料 / 手电筒 / 钳子 / 钥匙 | `HUD_icon_{bread,water,firewood,cloth,flashlight,pliers,key}` | **7 件专图，图形与名称一一对应** |
| 退烧药 / 止痛药 | 上一版共用 `INV_icon_medicine`（通用医疗箱） | **没有各自的正式物品图标**，属于"缺少正式图标" |

处理：

- 两件药品的 `icon` 改为空，改用**运行时绘制的明确占位图**：琥珀描边框 + `?` +
  独立一行「占位」；详情栏 / Tooltip 同时标注「图标待补」。
  **用 Control 画，不新增 PNG、不新增 `ART_UI` 号、不改任何候选素材。**
- `INV_icon_medicine` 保留给**分类按钮「药品」**（分类级使用是正确的，且场景里本来就用它），
  不再被当成物品图标。
- 新增机器可校验的 **`ICON_AUDIT`** 映射表（物品名 → 图标键，空串 = 必须占位），
  `verify()` 逐条核对：专图 7 / 占位 2 / **错误映射 0**，且每个非空键都检查文件真实存在。
  以后加新物品必须先在表里登记，否则自检直接失败。
- `verify()` 也检查每个有物品的格子「正式图标 / 占位图二选一」，杜绝空槽冒充。

## 四、选中 / 悬停 / 弹窗视觉一致性

- **选中 + 悬停**：Button 的 hover 与 pressed 样式在鼠标移入时可能互相抢，
  上一版会出现"两种高亮"或选中框消失。现在 `_on_slot_hover()` 对已选中的格子把
  `hover` 样式临时指到 `INV_slot_selected`，移开再取消覆盖 ——
  始终只呈现一套琥珀选中框（`ui011_hover-selected.png`）。
- **详情 / 弹窗按钮**：详情两键与弹窗加减键全部用 `region_rect` 裁透明边的九宫格样式；
  端到端测试断言弹窗 4 个按钮的 normal/hover/pressed/disabled 都是 `StyleBoxTexture`。
- **弹窗遮罩**保持 0.45 黑，底层详情栏仍可读；`ui011_dialog.png` 复看无重叠。
- 五态样张页 `ui011_states.png` 复看：格五态、按钮四态、分类三态、九宫格拉伸均正常。
