## 一、勘误背景说明

在 `TASK-SCENE-002` 交付过程中，仓库内正式归档的 [`docs/TASK-SCENE-002_交付报告.md`](TASK-SCENE-002_交付报告.md) 与实际工程代码 [`scripts/world/season1_layout.gd`](../scripts/world/season1_layout.gd) 完全一致；但上轮会话窗口输出的**简版聊天摘要**出现了早期草稿口径残留，导致两份报告文本在室外地标建筑数量、室内场景宽度、设备间归属位置、场景 Key 命名、NPC 姓名及安全屋大门坐标上存在不一致。

按照 `TASK-SCENE-003` 第二节要求：**不修改原有历史报告（`docs/TASK-SCENE-002_交付报告.md`）来掩盖历史记录**，特立本勘误说明，逐项核对并统一以当前 `场景制作` 分支实际代码与 [`docs/TASK-SCENE-002_交付报告.md`](TASK-SCENE-002_交付报告.md) 为准。
